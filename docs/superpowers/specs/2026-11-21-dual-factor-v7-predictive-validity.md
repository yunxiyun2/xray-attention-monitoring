## 1. 目的与结论边界

v6 的 EFA/PAF 没有通过，不能继续用逐项试删或更换指标来搜索一个可发表的因子解。v7 检查一个独立且可预先定义的问题：

> 在同一个 DROZY 特征矩阵上，“驱动衰减”与“分布—转移共变”两个理论分数，是否比一个单一疲劳总分提供可复现的增量预测价值？

本实验是预测效度分析，不是 EFA，也不声称两个潜因子已经存在。即使增量预测成立，也只能说明预定义分数在所测人群和任务中有补充关系，不能反向证明 v6 的潜因子结构。EFA Decision B 保持不变。

## 2. 样本与标签

- 输入：`results/dual_factor_efa/indicator_matrix.csv`，包含 FD、PSV、SA、FN、SE、GTE、SV、SDR、KSS。
- 窗口：30 秒窗、10 秒步长，仅使用 phase 0；同一条记录内窗口不重叠。
- 记录标签：每条记录的 KSS 必须唯一。清醒定义为 KSS ≤ 4，困倦定义为 KSS ≥ 6；KSS=5 不纳入二分类。
- 分析单位：被试。纳入同时具有至少一条清醒记录和至少一条困倦记录的配对被试。
- 每人的两种状态分数先在记录内平均，再对有多个记录的状态做记录等权平均。窗口不作为独立样本来增加样本量。
- 被试内标准化使用该被试所有可用记录，不使用标签信息；随后按上述清醒/困倦状态聚合。

首个正式运行若配对被试少于 8 人，或任一被试任一状态有效非重叠窗口少于 10 个，结果为 `not_evaluable`。代码不得填补窗口或放宽入组标准。

## 3. 固定特征与分数

七项指标的方向在分析前固定：

| 分数 | 定义 | 方向 |
|---|---|---|
| F1 | `mean(FD_z, -PSV_z, -SA_z, -FN_z)` | 越高表示驱动衰减假设更强 |
| F2 | `mean(SE_z, GTE_z, SV_z)` | 越高表示分布—转移共变假设更强 |
| global | `mean(F1, F2)` | 单一疲劳总分 |

其中 PSV 是扫视峰值速度均值，FN 是单位时间注视事件频率。GTE 按当前实现是相邻网格对的联合熵，不称为条件转移熵。

分数方向是理论约束，不由本次 AUC 结果选择或翻转。

## 4. 模型对照

所有模型使用相同的被试级留一交叉验证；留出某一被试时，其两条状态记录同时离开训练集。每折的训练集标准化和模型拟合不得接触留出被试。

| 模型 | 输入 | 作用 |
|---|---|---|
| `global` | global | 主基线 |
| `f1_only` | F1 | 检查单维解释 |
| `f2_only` | F2 | 检查单维解释 |
| `two_factor` | F1、F2 | 主增量模型 |
| `seven_feature` | 七项 `_z` 指标 | 以高容量堆叠作为次要参考，不用于证明潜因子 |

模型固定为 L2 正则逻辑回归，`C=0.1`，不进行调参或根据结果选择。二分类样本由清醒/困倦配对构成，不另设类别权重。若输入特征在训练折退化，运行失败，不得静默替换模型。

## 5. 指标与主判定

主效应量为 `AUC(two_factor) - AUC(global)`。重叠预测由相同的 10 折外样本预测组成。补充报告：

- ROC AUC、average precision、Brier score、log loss；
- 每个模型的 ROC 曲线；
- 以被试为整群、分层保留两种状态的重抽样 bootstrap，`B=2000`，给出 AUC 及差值的 95% 百分位区间；
- 逐被试留出预测表和每折训练/留出身份。

主判定在随机种子和门槛预注册后计算：

| 结果 | 判定 |
|---|---|
| point ΔAUC ≥ 0.05 且配对 bootstrap 95% 下界 > 0 | `incremental_supported` |
| point ΔAUC ≥ 0.05 但 95% 下界 ≤ 0 | `inconclusive` |
| point ΔAUC < 0 且 95% 上界 < 0 | `global_better` |
| 其余情况 | `inconclusive` |

不得因主判定不显著而改阈值、改用不同特征、切换分类器或删除不利被试。`seven_feature` 和单独 F1/F2 只作次要比较，不能替代主判定。

## 6. 数据与运行审计

每次运行必须保存：

- 原始输入 SHA256、配置 SHA256、运行目录和 UTC 时间；
- 配对被试列表、排除被试及原因、每人两种状态的有效窗口数；
- 固定分数定义和方向；
- 每折训练/留出被试、拟合参数或失败原因；
- 原始外样本预测、模型指标、bootstrap 结果；
- 结构化 `decision.json`、人读报告和图表。

输入中存在窗口重复主键、标签在记录内变化、缺失/非有限值、训练折类别不完整，或留出被试出现在训练折时，运行失败。不得覆盖旧结果目录。

## 7. 允许的解释

- `incremental_supported`：在该数据集、该配对样本和固定模型下，双分数相对单一总分的 AUC 有正向增量；仍不证明因果、潜因子或跨人群泛化。
- `inconclusive`：现有 10 人左右的配对样本不足以区分增量与抽样波动。
- `global_better`：预定义双分数没有表现出增量，单一总分更适合当前样本；这是合法的负结果。
- 结果前后都必须写明：小样本、被试级留出、KSS离散标签和 DROZY 场景会限制外推。

## 8. 不运行的内容

v7 不运行 CFA、外部数据验证、多群组不变性、神经网络或超参数搜索。v6 的结构结论不因预测结果而升级。若需要改特征定义、KSS 阈值或模型类别，须另立新 SPEC。
