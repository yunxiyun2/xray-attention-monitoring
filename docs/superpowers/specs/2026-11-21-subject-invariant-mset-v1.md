# SPEC v1：受试者不变多尺度眼电 Transformer（SI-MSET）

> 日期：2026-11-21。  
> 状态：设计完成，待 GPU 实验机执行。  
> 目标：为“跨被试清醒/困倦识别”建立一条不依赖 EFA 候选结构的原始 EOG 序列学习路线。  
> 配套计划：[Plan SI-MSET v1](../plans/2026-11-21-subject-invariant-mset-v1-plan.md)。

## 1. 研究问题

前序 EFA 没有支持稳定的双因子结构，且双分数未表现出相对单一总分的增量。继续对同一组统计指标做删改会形成结果驱动的模型搜索。本研究改用原始双通道 EOG，直接学习短时注视、扫视与缓慢眼动漂移的联合时间形态。

核心问题：

> 多尺度时序建模、受试者对抗约束和受试者内状态排序，能否提升未见被试的清醒/困倦判别能力？

本任务检验三类可证伪假设：

- H1：多尺度时序编码优于单尺度编码；
- H2：受试者对抗约束提高跨被试 AUC；
- H3：KSS 序数回归和受试者内清醒—困倦排序优于只优化二分类。

完整 SI-MSET 只有在 H1—H3 的消融方向一致时才具有方法学价值；主模型是否可用由统一外样本门槛决定。

## 2. 方法概览

模型名为 **Subject-Invariant Multi-Scale EOG Transformer（SI-MSET）**。

### 2.1 物理约束输入

每条记录在预处理后完成：

1. 0.5–30 Hz 零相位带通滤波和 Hampel 去伪迹；
2. 使用记录级中位数与 MAD 做稳健归一化，降低电极增益、个体基线和记录漂移差异；
3. 下采样到 128 Hz，形成 30 秒、3840 点的窗口；
4. 输入三个通道：`EOG-H`、`EOG-V` 和二维速度幅值；
5. 裁剪到 `[-8, 8]`，非有限值和退化窗口拒绝。

速度幅值由归一化后的 H/V 一阶差分计算。测试阶段不允许用测试被试的标签重新定标。

### 2.2 多尺度时序编码

先以步长 4 投影为 96 维 token，再用三个深度可分离卷积分支建模：

| 分支 | 核大小 | 膨胀 | 目标尺度 |
|---|---:|---:|---|
| fast | 7 | 1 | 扫视与短时瞬态 |
| medium | 15 | 2 | 注视片段和状态转换 |
| slow | 31 | 4 | 缓慢漂移和持续注意变化 |

三个分支经过门控融合；随后做 10 点自适应池化，把 30 秒窗口压缩为 96 个时间 token。加入正弦位置编码后输入 3 层、4 头 Transformer。注意力池化产生 96 维窗口表示。

### 2.3 受试者不变约束

窗口表示连接三个输出头：

- 二分类头：清醒/困倦 logit；
- 序数回归头：KSS 归一化到 `[0,1]` 后回归；
- 受试者分类头：通过梯度反转层尝试从窗口表示识别来源被试。

受试者分类只用于约束表示，不进入最终预测。对抗权重从 0 线性升到配置值，避免训练初期破坏生理特征。

### 2.4 受试者内相对疲劳损失

每个训练批次由若干完整配对受试者组成，每人包含清醒和困倦窗口。除 masked BCE 与 KSS 回归外，还要求：

```text
mean_binary_logit(drowsy) - mean_binary_logit(alert) >= margin
```

违反边界的部分形成 hinge loss。该约束表达“同一受试者困倦窗口的风险不应低于清醒窗口”，不要求不同受试者具有相同绝对 EOG 幅度。

数据增强仅包含小幅高斯噪声；不翻转时间或交换 H/V 轴。

## 3. 数据与划分

- 数据源：DROZY EDF 中的 EOG-H、EOG-V；KSS 来自数据集标签。
- 窗口：30 秒、10 秒步长；使用 I-VT 后的最少注视/扫视数筛除退化窗口。
- 训练可使用缓存中的全部有效窗口；主评价固定使用 phase 0 的非重叠窗口，与 v7 基线保持同一测试尺度。
- 二分类标签：KSS ≤ 4 为清醒，KSS ≥ 6 为困倦；KSS=5 只参与序数回归。
- 主评价样本：同时具有清醒和困倦记录的配对被试。其他被试可参与序数训练，但不进入主 AUC 配对评价。
- 外部验证：leave-one-subject-out（LOSO）。测试被试的所有窗口必须整体留出。
- 每个 LOSO 折从其余配对被试中轮换一个作为验证受试者，剩余被试作为训练集；验证集和测试集不重叠。
- 所有随机种子、折划分和预注册门槛写入运行清单。

## 4. 模型与训练

默认模型：

- `d_model=96`，3 个 Transformer 层，4 个注意力头，FFN 192，dropout 0.15；
- 批大小：每个 batch 4 名训练受试者，每人清醒/困倦各 8 个窗口；
- AdamW，初始学习率 `3e-4`，weight decay `1e-4`；
- 余弦退火，最多 60 epoch，验证集 patience 12；
- FP16/AMP 在 CUDA 上启用；
- BCE 权重 1.0、KSS 回归权重 0.5、配对排序权重 0.25、对抗权重最大 0.1；
- 所有超参数在正式运行前固定，不按测试集结果修改。

任一训练样本出现非有限信号、训练/验证/测试被试相交、训练批缺少两类配对或模型输出非有限时，该折失败并保留原因。

## 5. 对照与消融

固定以下四种模型变体：

| 变体 | 多尺度分支 | 对抗约束 | KSS+排序损失 |
|---|---:|---:|---:|
| `full` | 是 | 是 | 是 |
| `single_scale` | 否 | 是 | 是 |
| `no_adversarial` | 是 | 否 | 是 |
| `binary_only` | 是 | 是 | 否 |

同一运行可使用 `--variant` 逐个执行。收益结论以相同 LOSO 划分和相同数据缓存的成对比较为准。

参考基线为 v7 运行中已经产生的 `global` 外样本预测。只有被试、状态和标签对齐后才允许比较；缺失基线时不计算差值，也不替换成训练集内分数。

## 6. 评价与主判定

评价单位是被试状态：

1. 对每名测试被试分别聚合其清醒窗口和困倦窗口的风险，得到两个点；
2. 汇总 10 名配对被试形成 20 个被试状态样本；
3. 计算 subject-state ROC AUC、average precision、Brier 和 log loss；
4. 用整群 bootstrap（保留同一被试两种状态）2000 次计算置信区间；
5. 在同一重抽样样本上与 v7 `global` 计算配对 ΔAUC。

主模型满足以下全部条件时判定为 `supported`：

- subject-state AUC ≥ 0.75；
- bootstrap 95% 下界 > 0.50；
- 相对 v7 global 的 ΔAUC ≥ 0.05 且 bootstrap 下界 > 0。

否则：

- AUC 上界 < 0.50：`below_chance`；
- 未达到 supported 且并非 below_chance：`inconclusive`；
- 任一关键数据、模型或基线对齐失败：`not_evaluable`。

单尺度、无对抗和只二分类的消融只用于解释效果，不允许用测试集挑选最优变体。

- 每个 LOSO 折的训练/验证/测试被试；
- 最优 epoch、验证损失、最佳 checkpoint（可配置关闭）；
- 全部外样本窗口预测及聚合后的状态预测；
- 指标、bootstrap 样本与区间；
- 报告和 ROC/消融图。

## 8. 结论边界

若结果支持，只能说明 SI-MSET 在 DROZY 的 LOSO 评价和固定协议下优于基线，不能直接宣称跨设备、跨任务或临床可用。若结果不支持，应保留负结果。不得通过改用另一测试划分、移除不利被试、翻转输出标签或放松门槛来重新定义成功。

本方法不重启 EFA，也不把深度模型学到的表示解释为已经证实的两类心理或生理机制。
