## 1. 研究背景与动机

### 1.1 方向转换背景

上一阶段（X光安检有效关注识别）的实验工作（20名受试者、22维特征、三档融合、LOSO AUC 0.929）在工程上扎实，但研究目标与导师指定的"唯一执行版"（疲劳目光行为双因子模式研究 V1.1）不一致。核心差距在于：

| 上次唯一执行版要求 | 上次汇报实际 |
|---|---|
| 基于公开数据集（DROZY/OperatorEYEVP）发现双因子结构 | 仍是自采20人X光数据做检测 |
| 从"检测准确率"转向"认知机制问题" | 仍以AUC/融合/识别性能为主线 |
| 提取8个双因子指标做EFA/CFA | 提取22维场景特征做分类 |
| 第4周决策点：双因子是否可分离 | 无EFA结果，无法决策 |

**本 spec 的定位**：执行唯一执行版阶段一——在 DROZY 公开数据集上跑通"数据→预处理→8指标→EFA→决策"全链条，回答"呆滞与发散能否统计分离"。

### 1.2 科学问题

能否在公开数据集的眼动信号上，实证分离出"呆滞"和"发散"两种目光行为成分？

子问题：
- **可分离性**：呆滞与发散是否为统计上可分离的两个独立维度？
- **方向一致性**：各指标在疲劳条件下的变化方向是否符合假设预期？
- **结构稳定性**：因子结构在不同被试、不同疲劳程度下是否稳健？

### 1.3 核心假设

| 编号 | 假设 | 预期 | 证伪条件 |
|---|---|---|---|
| H1（呆滞型） | 疲劳导致眼动输出端效率下降 | 注视时长↑、扫视速度↓、扫视幅度↓、注视频率↓ | 方向不一致或无显著载荷 |
| H2（发散型） | 疲劳导致注视控制端调节失灵 | 空间熵↑、转移熵↑、空间方差↑、方向随机性↑ | 方向不一致或无显著载荷 |
| H3（组合假设） | 疲劳目光行为=H1+H2的线性组合 | EFA提取两因子且相关<0.70 | 仅一个因子或相关>0.85 |

## 2. 数据来源

### 2.1 DROZY 数据集

DROZY（ULg Multimodality Drowsiness Database）是比利时列日大学使用 Microsoft Kinect v2 采集的多模态嗜睡数据库。

| 维度 | 详情 |
|---|---|
| 被试数 | 14名（编号1-14） |
| 有效测试数 | 37个（每被试3次，缺失5个：9-1、10-2、12-2、12-3、13-3；7-1未进行） |
| 采样设备 | Kinect v2 近红外+深度 + 多导睡眠图（PSG） |
| 任务 | 精神运动警觉性测试（PVT），每次约10分钟 |

### 2.2 眼动数据来源

DROZY 不含独立红外眼动仪的注视点坐标数据。眼动信号以**眼电图（EOG）**形式存在于 PSG/EDF 文件中：

| 通道 | 采样率 | 说明 |
|---|---|---|
| EOG-V | 512 Hz | 垂直眼电，反映垂直方向眼动 |
| EOG-H | 512 Hz | 水平眼电，反映水平方向眼动 |
| Cam-Sync | 512 Hz | 帧同步方波，用于与视频帧对齐 |

**技术决策**：将 (EOG-H, EOG-V) 视为二维眼动位置代理。虽单位为电压（μV）而非像素，但其相对分布模式（熵、方差、方向分布）足以反映目光行为的空间特征。这是在无独立眼动仪条件下的合理近似。

### 2.3 疲劳标签

| 标签 | 来源 | 格式 | 用途 |
|---|---|---|---|
| KSS评分 | `KSS.txt` | 14行×3列，1-9分 | 主观嗜睡度，二分类阈值 |
| PVT反应时 | `pvt-rt/{subj}-{test}.csv` | 刺激时间;反应时间 | 行为疲劳度量 |

KSS 评分矩阵（行=被试1-14，列=测试1-3）：
```
3 6 7 / 3 7 6 / 2 3 4 / 4 8 9 / 3 7 8 / 2 3 7 / 0 4 9
2 6 8 / 2 6 8 / 3 6 7 / 4 7 7 / 2 5 6 / 6 3 7 / 5 7 8
```

**疲劳二分类**：KSS ≤ 4 为清醒（alert），KSS ≥ 6 为困倦（drowsy）。KSS=5 为中间态，在二分类中排除或单独分析。被试7测试1（KSS=0）排除。

### 2.4 辅助模态

| 模态 | 路径 | 用途 |
|---|---|---|
| 近红外视频 | `videos_i8/{subj}-{test}.mp4` | 后续可做视频注视估计验证（阶段四） |
| 68点人脸标注 | `annotations-auto/{subj}-{test}-s2.txt` | 后续可做PERCLOS交叉验证 |
| 相机内参 | `kinect-intrinsics.yaml` | 后续视频注视估计标定用 |
| 帧时间戳 | `timestamps/{subj}-{test}.txt` | PSG与视频帧对齐 |

阶段一仅使用 EOG + KSS + PVT，视频模态留待阶段四跨模态验证。

## 3. 八个核心指标

### 3.1 指标定义

所有指标在30秒滑动窗内计算，步长10秒，按被试内 z-score 标准化。

#### 呆滞因子（Hypoactive）——眼动输出端效率下降

| 编号 | 指标 | 符号 | 计算方式 | 疲劳预期 |
|---|---|---|---|---|
| 1 | 平均注视时长 | FD | 注视段（fixation）时长的均值 | ↑ 增加 |
| 2 | 扫视峰值速度 | PSV | 扫视段（saccade）EOG速度峰值的均值 | ↓ 下降 |
| 3 | 扫视幅度 | SA | 扫视起点到终点的EOG位移量 | ↓ 减小 |
| 4 | 注视频率 | FN | 单位时间内注视事件次数 | ↓ 降低 |

#### 发散因子（Diffuse）——注视控制端调节失灵

| 编号 | 指标 | 符号 | 计算方式 | 疲劳预期 |
|---|---|---|---|---|
| 5 | 空间熵 | SE | 注视点(EOG-H,EOG-V)在空间网格中分布的信息熵 | ↑ 升高 |
| 6 | 注视转移熵 | GTE | 注视点在空间区域间转移模式的信息熵 | ↑ 升高 |
| 7 | 注视点空间方差 | SV | 注视点(EOG-H,EOG-V)坐标的离散程度（马氏距离方差） | ↑ 增大 |
| 8 | 扫视方向随机性 | SDR | 扫视角度分布与均匀分布的KL散度 | ↑ 增加 |

### 3.2 事件检测算法

采用 **I-VT（Velocity-Threshold）** 算法在 EOG 信号上提取注视/扫视事件：

1. **信号预处理**：带通滤波（0.5-30 Hz）去除基线漂移与高频噪声
2. **速度计算**：一阶差分得到 EOG 速度信号 `v = sqrt(dH² + dV²)`
3. **事件分类**：
   - 速度 < 阈值 `v_th` → 注视（Fixation）
   - 速度 ≥ 阈值 `v_th` → 扫视（Saccade）
4. **事件合并**：最短注视时长 100ms，最短扫视时长 20ms（合并过短片段）

速度阈值 `v_th` 采用数据驱动方式确定（Oculus/DIKI 标准：基于速度分布的百分位数），在正式执行前做参数敏感性测试。

### 3.3 空间网格化

空间熵与转移熵的计算需要将 (EOG-H, EOG-V) 平面网格化：
- 将每个窗口内的注视点投影到 2D 网格（建议 5×5 或自适应分箱）
- 空间熵 SE = `-Σ p_i log(p_i)`，其中 `p_i` 为注视点落入第 i 格的概率
- 转移熵 GTE = 基于注视序列在网格区域间的转移矩阵计算

## 4. 预处理管道

### 4.1 数据读取

```
EDF文件 (psg/{subj}-{test}.edf, 512Hz)
  → pyedflib/MNE 读取 EOG-H, EOG-V 通道
  → 提取 Cam-Sync 通道用于帧对齐
  → 输出: (EOG_H[], EOG_V[], timestamps[])
```

### 4.2 信号预处理

| 步骤 | 方法 | 参数 | 目的 |
|---|---|---|---|
| 去基线漂移 | 高通滤波 | 0.5 Hz Butterworth | 去除EOG基线漂移 |
| 去高频噪声 | 低通滤波 | 30 Hz Butterworth | 去除肌电噪声 |
| 去伪迹 | 中值滤波或Hampel滤波 | 窗口=51 | 去除眨眼等离群点 |
| 信号对齐 | Cam-Sync同步 | - | EOG与PVT/视频帧对齐 |

### 4.3 窗口化

| 参数 | 值 | 理由 |
|---|---|---|
| 窗口长度 | 30秒 | 与PVT任务周期对齐，保证窗口内有足够眼动事件 |
| 步长 | 10秒 | 66.7%重叠，增加观测样本量 |
| 最小有效样本 | ≥5个注视事件+≥3个扫视事件 | 不足则标记缺失 |

### 4.4 标准化

- **被试内 z-score**：每个指标在每个被试内做 `(x - mean_subj) / std_subj`
- 目的：消除个体间EOG电压基线差异，聚焦疲劳引起的相对变化
- 在 EFA 之前执行

## 5. 探索性因子分析（EFA）

### 5.1 前置检验

| 检验 | 指标 | 合格标准 |
|---|---|---|
| KMO | Kaiser-Meyer-Olkin采样充分性 | > 0.50（>0.60为佳） |
| Bartlett球形检验 | 卡方值、p值 | p < 0.05（拒绝"指标间无相关"零假设） |

若 KMO < 0.50 或 Bartlett 不显著，说明数据不适合因子分析，需检查指标计算或样本量。

### 5.2 因子提取

| 参数 | 设置 | 理由 |
|---|---|---|
| 提取方法 | 主轴因子法（PAF） | 不假设多元正态，适合小样本 |
| 旋转 | Promax 斜交旋转 | 允许因子相关，符合"双因子可能相关"假设 |
| 因子数确定 | 平行分析（ParAnalysis）+ 碎石图 | 数据驱动，不靠主观判断 |
| 最大因子数 | 4 | 先验假设2个，上限放宽到4以检测过拟合 |

### 5.3 结果报告

必须报告以下全部内容：

1. **碎石图 + 平行分析图**：确定最优因子数
2. **累计方差解释率**：要求 > 60%
3. **因子载荷矩阵**：标注各指标在两因子上的载荷
4. **交叉载荷**：要求 < 0.30
5. **因子相关矩阵**：两因子相关系数 r
6. **KMO 与 Bartlett 检验结果**

### 5.4 核心决策判据

| 判据 | 阈值 | 结论 |
|---|---|---|
| 两因子相关 < 0.70 且载荷清晰（>0.5） | 满足 | **双因子可分离**，假设初步成立，进入CFA验证 |
| 两因子相关 > 0.85 或仅提取一个因子 | 满足 | **双因子不可分离**，假设被推翻，转向单维度模型 |
| 0.70 ≤ r ≤ 0.85 | 中间 | 因子结构模糊，检查指标计算或考虑剔除低载荷指标 |

## 8. 风险与预案

| 风险 | 判据 | 预案 |
|---|---|---|
| EOG信号质量差 | 大量伪迹或通道缺失 | Hampel滤波去伪迹；若仍不可用，改用NIR视频+人脸landmark估计注视 |
| 窗口内事件数不足 | <5个注视或<3个扫视 | 放宽窗口到60秒，或降低min_fixations到3 |
| KMO < 0.50 | 采样充分性不足 | 检查指标计算是否有误；增加窗口数（减小步长）；考虑剔除低质量指标 |
| 仅提取一个因子 | 最优因子数为1 | 双因子假设被推翻，如实报告否定结果，转向单维度+多维指标结构 |
| 两因子相关 > 0.85 | 因子高度共线 | 重新分配指标或合并为单因子；检查是否有指标同时载荷于两因子 |
| 8指标方向与假设不符 | 部分↑↓相反 | 如实报告，分析可能原因（EOG代理局限、任务特异性），不强行解读 |

**关键原则**：否定结果也是合格结果。只要分析过程严谨、判定清晰、代码可复现，无论双因子是否成立都算合格。
