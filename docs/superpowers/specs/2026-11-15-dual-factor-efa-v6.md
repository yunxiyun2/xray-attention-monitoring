## 1. 背景：v5 Decision B 与根因

### 1.1 v5 执行结果

v5 在 DROZY 真实数据上正式执行（运行目录 `20261109T154643Z-aaffec43`），决策为 **B**：

- 所有 PAF 模型失败：Heywood case（共同度越界 [0,1]）或不收敛。
- 平行分析三相位一致建议 2 因子（`dimensions_ok=True`），但无法利用。
- 模拟证书有效（`diagnostic_checks_passed=True, latent_power_validated=False`）。

### 1.2 根因诊断

PAF 失败的直接原因是 **F2 仅有 2 个指标（SE, GTE）且两者相关极高（r≈0.90）**：

- SE 共同度持续下降，GTE 共同度持续上升至超过 1.0（Heywood case）。
- 4/2 结构中 F2 的指标数等于因子数约束下限，统计不可识别。
- 这是 4/2 结构的固有限制，非代码 bug。SPEC v5 §5 已预期此结果。

### 1.3 SPEC v5 的修正许可

SPEC v5 §6.1 Decision B："指出具体问题；只允许一份下一版本修正建议，不无限试删或软化门槛。" §E2.4："与六项冲突→B，提出新版本候选及独立验证需求。" §7.1："增加独立理论指标或独立数据的方案需另版设计。"

v6 即为该唯一修正建议。

## 2. 修正方案：SV 加入 F2，4/3 结构

### 2.1 新候选结构

| 成分 | 指标 | 指标数 | 预期疲劳方向 |
|---|---|---|---|
| F1：驱动衰减假设成分 | FD, PSV, SA, FN | 4 | FD↑，PSV↓，SA↓，FN↓ |
| F2：分布—转移失序假设成分 | SE, GTE, SV | 3 | SE↑，GTE↑，SV↑ |

保留指标集从 6 项扩展为 7 项（加入 SV）。SDR 仍在八指标基线和探索性附录，不进入主结构。

### 2.2 选择 SV 的经验依据

v5 真实数据相关矩阵（8 指标，Phase 0）中 SV 与 F2 指标的相关：

| 指标对 | 相关系数 | 说明 |
|---|---|---|
| SV–SE | -0.365 | 中等负相关 |
| SV–GTE | -0.293 | 中等负相关 |
| SV–SDR | 0.003 | 近零 |

SV 是唯一与 SE/GTE 有实质关联的候选指标。SDR 与 SE/GTE 相关近零（0.00, 0.05），加入 F2 无助于因子估计。

SV 与 F1 指标的相关：FD=0.328, PSV=0.194, SA=0.356, FN=0.152。SV 与 F1 有中等正相关，存在交叉载荷风险。v3 历史修剪中 SV 因交叉载荷 0.469 被移除，但那是旧方法（principal 而非真 PAF）的结果。v6 使用修正后的 PAF 重新评估。

### 2.3 SV 的理论定位

**SV = 注视点二维协方差矩阵的迹**（`indicators.py` L100-106）。测量注视点在二维空间中的离散程度。

SV 是空间分布指标，与 SE（网格占据熵）和 GTE（转移熵）共同刻画"分布—转移"维度：
- SE 衡量注视覆盖了多少网格单元及其均匀性。
- GTE 衡量注视转移路径的可预测性。
- SV 衡量注视点在连续空间中的离散范围。

三者从不同粒度（离散网格、转移序列、连续空间）刻画空间分布行为，构念上属于同一维度。

### 2.4 SV 的负相关解释

SV 与 SE/GTE 负相关意味着：注视点空间离散度高（SV↑）时，网格占据熵反而低（SE↓）。这表示注视点虽在空间上分散，但集中在少数网格单元内（网格粒度粗于空间离散度时出现此现象）。这不是测量错误，而是不同粒度指标间的互补关系。

在因子模型中，SV 将在 F2 上有**负载荷**（SE/GTE 为正载荷）。C2 判据检查**主载荷绝对值**≥0.50，负载荷满足此条件。方向一致性在因子得分层面检查（§4）。

## 3. 方向处理与因子解释

### 3.1 指标级方向

| 指标 | 预期疲劳方向 | F2 载荷符号 | 一致性 |
|---|---|---|---|
| SE | ↑（+1） | 正 | 一致 |
| GTE | ↑（+1） | 正 | 一致 |
| SV | ↑（+1） | 负 | 反转 |

SV 在 F2 上负载荷意味着：F2↑ → SV↓。如果疲劳 → F2↑，则疲劳 → SV↓，与 SV 预期方向（+1）矛盾。

### 3.2 因子级方向检查

SPEC v5 §E4.1 要求："如果要将潜成分直接命名为驱动衰减/失序，还须检查锚定后的 pattern 符号与预期共同变化一致，以及成分得分配对差值的 95% CI 在预期方向。"

v6 补充规则：
1. **主方向由多数指标决定**：F2 中 SE 和 GTE 为正载荷且方向一致，SV 为负载荷。如果 SE/GTE 的配对效度为 supported（方向正确且 p<0.05），即使 SV 方向反转，F2 因子得分仍可能在预期方向（↑ with fatigue）。
2. **SV 方向反转的报告**：如果 SV 配对效度为 opposite（疲劳时 SV↓），在报告中明确标注。F2 使用中性名称"分布—转移共变成分"而非"失序增强"。
3. **不翻转 SV 方向**：SV 的预期方向保持 +1（理论预测：疲劳增加空间离散度）。历史数值不翻转（与 SDR 规则一致）。如果实证方向相反，如实报告。

### 3.3 因子命名规则

- 如果 SE/GTE 配对 supported 且 SV inconclusive/opposite：F2 可条件性称为"分布—转移共变成分"，SE/GTE 子维度为"熵增"，SV 子维度为"空间收缩"。不统称"失序增强"。
- 如果 SE/GTE 配对 inconclusive：F2 仅称"分布—转移共变成分"。

## 4. 模拟验证要求

### 4.1 新合成数据生成器

v6 模拟使用 4/3 结构的合成数据：

```text
loadings = zeros((7, 2))
loadings[:4, 0] = [.9, -.9, -.9, -.9]   # F1: FD, PSV, SA, FN
loadings[4:, 1] = [.9, .9, -.6]          # F2: SE, GTE, SV（SV 负载荷）
```

SV 载荷绝对值 0.6 < 0.9，反映其与 SE/GTE 的较弱关联。载荷符号为负，反映真实数据中的负相关。

### 4.2 模拟场景

v5 的 7 类场景保留，更新为 7 指标 4/3 结构：

| 场景 | 真值结构 | 预期信号检测 | 预期潜因子接受 |
|---|---|---|---|
| null | 无因子 | 0/200 | 0/200 |
| single | 单因子 | 0/200 | 0/200 |
| two_4_3 | 双因子 4/3（SV 负载荷） | ≥150/200 | ≥160/200 |
| correlated_two | 高相关双因子 ρ=0.85 | 0/200 | 0/200 |
| cross_loading | SV 交叉载荷 0.45 | 200/200 | 0/200 |
| heterogeneous | 7 人归属改变 | ~130/200 | 0/200 |
| two_nonnormal | 非正态双因子 4/3 | ≥150/200 | ≥160/200 |

**关键验收线**：`two_4_3` 场景潜因子 A 接受率 ≥ 0.80（160/200）。这是 v6 修正有效性的核心检验——如果合成 4/3 数据上 PAF 仍无法收敛/接受，则修正方向本身有问题。

### 4.3 潜因子接受判定

继承 v5 的完整 `protocol_support()` 逻辑：
1. 三相位 PAF 收敛 + C0—C4 全部达标。
2. 整人 cluster bootstrap B=200，C5 七项门槛全通过。

`latent_power_validated = (two_4_3 接受率 ≥ 0.80)`。

### 4.4 诊断校准

继承 v5 的可观测信号检测校准。信号检测参数不变（`coherence_min=0.5, eigen_floor=1.0`）。
