## 1. 主线：预注册指标修剪阶梯（Pruning Ladder）

### 1.1 设计原则

路径 B 允许"剔除/替换指标后重做"，但逐个试剔除直到通过，会构成研究者自由度（garden of forking paths）。因此本版不指定"剔 SV"这种具体答案，而是**预注册一条确定性修剪规则**：规则给定数据后剔除对象唯一确定，无人工挑选空间；同时以硬性下限防止把指标剔到只剩骨架来"凑通过"。

### 1.2 阶梯结构

每个 rung 在当前保留指标集上提取 **2 因子固定解**（PAF + Promax，与 v2 相同参数），评估判据；未通过则按规则剔除 1 个指标进入下一 rung。

```
Rung 0: 全部 8 指标（= v2 基线 2 因子解，已知不通过）
   │ 按 §1.3 规则剔除 1 个
Rung 1: 7 指标 → 评估 → 未通过则再剔除 1 个
Rung 2: 6 指标 → 评估 → 未通过则再剔除 1 个
Rung 3: 5 指标 → 评估（硬性下限，到此为止）
```

### 1.3 修剪规则（确定性，优先级从高到低）

设当前 rung 的 2 因子解已算出。按以下优先级选择**唯一**剔除对象：

| 优先级 | 触发条件 | 剔除对象 | 理由码 |
|---|---|---|---|
| 1 | 最大交叉载荷 ≥ 0.30（C3 未达标） | 交叉载荷最高的那个指标 | `cross_loading` |
| 2 | 存在主载荷 < 0.50 的指标（C2' 未达标） | 主载荷最低的那个指标 | `low_loading` |
| 3 | 仅 C1 未达标（载荷干净但方差不足） | 主载荷最低的指标 | `variance_driven` |
| 4 | C4 未达标（\|r\| ≥ 0.70） | 不剔除——立即终止 | `factor_collinear` |

规则 4 的含义：因子共线不是指标问题，剔除指标无法修复，直接走路径 C。

### 1.4 终止条件（硬性）

| 条件 | 后果 |
|---|---|
| 某 rung 的 C1-C4 全部达标 | 阶梯停止，该 rung 为最终解 |
| 保留指标 < 5，或任一假设因子剩余指标 < 2 | 阶梯停止，判定路径 C |
| 剔除次数 > 3 | 阶梯停止，判定路径 C |
| 触发规则 4 | 立即停止，判定路径 C |

假设因子分组（固定）：呆滞 = {FD, PSV, SA, FN}，发散 = {SE, GTE, SV, SDR}。

### 1.5 判据（严格化版，预注册）

在 v2 C1-C5 基础上修正两处 v2 的模糊点，方向一律从严：

| 编号 | 判据 | 阈值 | 相对 v2 的变化 |
|---|---|---|---|
| C1 | 累计方差解释率（**2 因子解**） | >0.60 | 明确：评估对象是 2 因子解，不是平行分析选出的 k 因子解（v2 用 3 因子解的 69.2% 评估，属判据与假设错位） |
| C2' | **所有保留指标**的主载荷 ≥0.50 | ≥0.50 | v2 只查全矩阵最大载荷 >0.50，无法发现 SDR=0.124 这种"载荷不清"；从严改为逐指标检查（对应导师"2 因子解载荷不清，就不得写成立"） |
| C3 | 最大交叉载荷 | <0.30 | 不变 |
| C4 | 两因子相关 | \|r\|<0.70 | 不变 |
| C5 | 修正后指标集上，窗口级/被试级/LOSO/非重叠的因子数结论一致 | 一致 | 评估对象改为**最终保留指标集** |

### 1.6 平行分析的角色（预注册）

平行分析在每个 rung 照常计算并**逐 rung 报告**，但其结论不作为 A/C 判定的否决项——导师给出的约束性判据是交叉载荷与载荷清晰度（"若交叉载荷仍≥0.3，或 2 因子解载荷不清，就不得写'双因子可分离成立'"）。若最终 rung 通过 C1-C4 但平行分析仍建议 ≠2 个因子，报告**必须**带显著的维度警示（dimensionality caveat）：

> "2 因子解在保留指标上满足全部判据，但平行分析建议 k 维结构；双因子结论应理解为'保留指标子集上两因子可分离'，而非'数据整体为二维'。"

该警示不得省略、不得弱化。

### 1.7 判定映射（三选一的后续收口）

| 阶梯结局 | 判定 | 下一步 |
|---|---|---|
| 某 rung C1-C4 全过 + C5 一致 | **A：支持双因子（保留指标集）** | 启动 CFA 预注册（P1-1） |
| 某 rung C1-C4 全过 + C5 不一致 | **A（附不稳警示）**：支持但被试级不稳 | CFA 中重点考察结构稳定性 |
| 到达下限仍未通过 / 触发规则 4 | **C：转结构**（三因子或单维） | 对最终保留集做 3 因子解解释性分析，或转单维模型；如实写"双因子假设在 DROZY 上不成立" |

不存在"再修一修"的第四选项。**阶梯的任何结局都是终局，均为合格决策。**

### 1.8 剔除的实质性论证要求

每个被剔除指标必须在报告中标注：

1. 剔除时的判据数值（交叉载荷 / 主载荷 / 方差贡献）；
2. 代理效度类别（幅度依赖型 / 时间型 / 分布形态型，来自 v2 构念效度报告）；
3. 实质性解释一句话（如：SV 为幅度依赖型指标，EOG 电位基线漂移导致其方差混入个体差异，与分布形态型的 SE/GTE 不同源）。

若最终剔除清单与代理效度类别系统性吻合（如剔除的多为幅度依赖型），这本身就是**EOG 代理适用边界**的发现，写入论文局限章。

### 1.9 结论表述的强制限定

若判定为 A，所有对外表述（汇报、论文、答辩）必须写成：

- ✅ "在保留的 N 项指标上，呆滞与发散两因子可分离"（N < 8 时）
- ❌ "八项指标双因子可分离"（除非 N=8，已知不可能）
- ❌ 省略"保留指标集"限定的任何简写

## 6. 合格标准

### 6.1 最低合格线

| 项 | 标准 |
|---|---|
| 预注册 | 修剪规则、阈值、终止条件在运行前已固化（本文件 §1） |
| 阶梯透明 | 逐 rung 记录落盘，每个剔除附判据数值 + 代理效度类别 + 实质解释 |
| 判定终局 | A / C 三选一明确收口，无"再修一修" |
| 表述限定 | 判定 A 时结论带"保留指标集"限定；PA≠2 时带维度警示 |
| 敏感性 | 最终集上四种敏感性完成，C5 如实报告 |
| 辅线 | 文献表 DOI 经核实或如实标"待核实" |

### 6.2 不合格线（需避免）

- 结果导向地手工挑选剔除对象（绕过预注册规则）
- 判定 A 但省略"保留指标集"限定或维度警示
- 只报最终 rung、隐藏中间剔除过程
- 为凑 C1 阈值把指标剔到下限以下
- 辅线编造或凭记忆填 DOI

## 7. 风险与预案

| 风险 | 判据 | 预案 |
|---|---|---|
| 修剪后 2 因子方差仍 <60% | C1 持续未达标 | 规则 3 最多再剔 1 个；仍不过 → 路径 C，如实报告 |
| 发散簇剔到只剩 SE/GTE | 发散剩余 2 项 | 允许（下限=2），但结论必须写明"发散成分仅由 SE/GTE 支撑" |
| 被试级 EFA 在 5-6 指标上不收敛 | C5 无法评估 | 如实报告不收敛（n=14 局限），C5 记"不可评估"，判定降级为 A（附不稳警示）或按 C5 未达标处理，取从严者 |
| 修正后 LOSO 某几折交叉载荷反弹 | 个别折 >0.30 | 报告反弹折数与被试编号，若 ≥1/3 折反弹则判定降级为"支持但不稳" |
| 剔除清单与代理效度类别不吻合 | 如剔除了分布形态型指标 | 不阻塞判定，但在报告中讨论替代解释（网格化参数 / 构念定义问题），列入局限 |
