> 前序结果：[v1 执行记录](../../dual_factor/si_mset_v1_execution_log.md)、[v1.1 执行记录](../../dual_factor/si_mset_v1_1_execution_log.md)。
> 本次结果：[v1.2 执行记录](../../dual_factor/si_mset_v1_2_execution_log.md)。

## 1. 研究问题

v1 的被试状态 AUC 为 0.750，但差值区间较宽；v1.1 扩容量后降至 0.720，同时 log loss 从 0.692 升至 1.289。现有证据无法区分：

1. 0.750 是否是单次随机种子和 checkpoint 的偶然结果；
2. 跨被试排序误差是否主要来自不同被试的概率尺度/偏移；
3. 更大的模型是否确实增加泛化能力。

v1.2 检验两个独立问题：

- **R1 稳定性**：同一 v1 架构独立训练多个随机种子并融合后，跨被试 AUC 是否仍接近或高于 0.75；
- **R2 校准**：在不使用测试标签、只使用测试被试窗口分数分布的情况下，被试内秩标准化能否提高跨被试状态 AUC。

v1.2 不通过扩大模型解决当前问题。模型容量、损失和输入回到 v1 配置。

## 2. 数据与训练协议

- 复用缓存 `results/eog_si_mset/cache_v1`；
- 10 名配对被试、10 折 LOSO 和 phase 0 测试窗口均保持 v1 不变；
- 模型：96 维、3 层 Transformer、4 头、96 token；
- 每个配置固定 3 个预注册种子：`2026112121`、`2026112122`、`2026112123`；
- 每个 LOSO 折针对三个种子分别训练和选择 checkpoint；
- 验证使用一名从未参与该折训练的被试，验证窗口在折开始时固定，所有 epoch 复用；
- 最大 80 epoch、24 batch/epoch，patience 16；
- 三个 seed 的窗口 logit 先等权平均，再进入状态评价；
- 任一 seed 失败则整折标记失败，不用其余 seed 拼接结果。

扩大训练预算不是 v1.2 的主要变量；使用 80 epoch 是为了给固定验证集留出收敛空间，三个种子共同提供稳定性估计。

## 3. 受试者内校准

所有校准只使用测试被试的窗口预测分布，不读取标签。

把每个窗口的二分类概率转为 logit `l`。对每个测试被试分别计算：

| 方法 | 定义 |
|---|---|
| `raw` | 原始 logit |
| `center` | `l - median_subject(l)` |
| `zscore` | `(l - mean_subject(l)) / std_subject(l)` |
| `rank` | 将被试内全部测试窗口的 logit 转为平均秩百分位 |

校准后按清醒/困倦状态取均值，再计算 10 名被试的状态 AUC。每个被试至少需要 20 个非重叠测试窗口；不足时主分析 `not_evaluable`。

该步骤是离线、转导式测试时校准，要求一次评价包含同一被试足够多的未标注窗口。它不能用于单窗口实时预测，也不能称为跨设备泛化。

## 4. 主次终点

### 主终点

**三 seed 融合 + 被试内 rank 校准** 的状态 AUC：

- ≥ 0.75；
- 被试整群 bootstrap 95% 下界 > 0.50；
- 相对同一融合预测的 `raw` 方法，AUC 提升 ≥ 0.05 且下界 > 0；
- 相对 v7 `global`，AUC 提升 ≥ 0.05 且下界 > 0。

四项同时满足才是 `supported`。

### 次要终点

- 三个单 seed 的 AUC 分布；
- seed 平均 `raw` 与 rank/center/z-score 的差值；
- AP、Brier、log loss 和逐被试排序；
- 三种校准方法不得替代主方法，不得择优后重写主结论。

若主终点未通过：

- rank 方法上界 < 0.50：`below_chance`；
- 其余：`inconclusive`；
- 数据、某个 seed 或输出不完整：`not_evaluable`。

## 5. 预期证据链

一次完整运行应产生：

- 每折每 seed 的训练历史、最佳 epoch 和测试预测；
- 单 seed、三 seed 融合的逐窗口预测；
- raw/center/z-score/rank 四种状态预测及 bootstrap；
- 主判定；
- 训练曲线、ROC、AUC 区间和校准比较图。

只有完成上述产物，才能回答 R1/R2。若多个 seed 的测试 AUC 差异很大，必须在结论中突出随机波动，不能只报告最好 seed。

## 6. 终止与报告边界

- v1.2 只运行一次完整协议，不根据结果继续更换校准公式或增加 seed；
- 不据测试集调整 epoch、dropout 或模型宽度；
- 所有结果只适用于 DROZY 当前缓存；
- 无标签主体校准是部署假设的一部分，报告中必须明确；
- 通过主终点仍不代表通用疲劳检测器，只代表在该小样本 LOSO 和校准条件下优于同源基线。
