# 有效关注阈值实验与研究仓库设计

## 目标

建立一个面向 X 光安检员关键区域关注识别的可复现研究仓库，并完成首个任务级候选阈值实验。实验从已有的逐采样注视-目标距离误差序列中选择有效关注阈值，为后续时序模型和多模态模型提供可解释的关注判定基础。

## 研究定义

- `alert`：有效关注标签（正类）。
- `sleepy`：无效或不足关注标签（负类）。
- 原始行为信号：逐采样注视-目标距离误差序列，即 webcam gaze 估计位置与当前目标区域之间的欧氏距离，单位为屏幕像素。
- 分析单位：一名受试者在一个任务难度（`easy` 或 `hard`）和一个关注状态下的一段完整任务序列。
- 本阶段不将连续长度解释为秒，因为现有误差序列未附可靠采样率和时间戳；连续长度如被计算，单位为采样点。

## 数据边界

本阶段仅读取 `Distan_error（原20）/` 下的 80 段 `all_errors.txt` 序列：20 名受试者 x 2 个任务难度 x 2 个标签。`data/` 下的原始视频和目标点坐标保留不动，后续面部特征或多模态研究再读取。

任何源码、配置、文档和小型结果表可以纳入版本控制；原始视频、原始误差序列、模型权重和大体积中间结果不得纳入版本控制。

## 仓库结构

```text
configs/                         # 实验参数与路径配置
docs/                            # 数据说明、方法说明、设计与实验记录
experiments/
  threshold_selection/           # 阈值实验的可执行入口
manuscript/                      # 论文提纲、章节草稿、图表清单与参考文献
results/
  threshold_selection/           # 可再生成的表格、图和实验摘要
src/xray_attention/
  data/                          # 数据发现、读取、元数据与校验
  attention/                     # 注视偏差指标、阈值规则、统计评价
  models/                        # 后续：面部、时序、融合模型
tests/                           # 对数据读取、指标计算和实验切分的测试
```

项目采用 `src` 布局。每个实验由一份配置驱动，输出目录以实验名区分，并保存运行参数、汇总表和图表，保证论文图表能由同一命令重新生成。

## 候选阈值实验

### 特征与候选阈值

对每段任务序列和每个候选距离阈值 `t`，计算：

- 目标区域内采样占比：`p_t = mean(error <= t)`；
- 单次任务平均注视偏差；
- 误差标准差和中位数；
- 最长连续低误差片段长度（单位：采样点）。

第一轮候选阈值为 `50, 75, ..., 1000 px`。运行后根据总体误差分布检查边界是否过窄或过宽；若最优点位于边界，将扩展候选区间并完整重跑。

### 评价与阈值选择

将 `p_t` 作为阈值 `t` 的主要关注量化指标，并以 `alert=1`、`sleepy=0` 评价其区分能力。每一个候选阈值将报告：

- 任务级 ROC-AUC；
- 平衡准确率；
- alert 与 sleepy 的指标分布、均值差和效应量；
- easy、hard 以及合并数据上的结果。

为了避免用测试受试者选择阈值，采用嵌套留一受试者交叉验证：

1. 外层每次留出一名受试者，保留其四段任务序列用于测试。
2. 在其余 19 名受试者中，为每个候选阈值计算任务级判别表现，并按“平均 ROC-AUC 优先、平均平衡准确率次之、阈值更小再次之”的规则选择阈值。
3. 在训练受试者上确定 `p_t` 的判别临界值；仅将这一阈值与临界值应用于外层留出受试者。
4. 汇总 20 个外层测试折的性能、被选择次数及选中阈值分布。

最终推荐阈值不是单一折的最优值，而是外层折中选择最频繁、且性能稳定的候选值。若 easy 和 hard 的结果呈现明显且稳定的差异，则分别报告难度特异阈值与统一阈值的性能，并以性能差异决定是否保留双阈值。

## 当前范围与后续阶段

首阶段只完成数据读取、候选阈值选择、统计输出和仓库骨架，不训练深度学习模型，也不从视频重新估计 gaze。后续模型研究将在此基础上增加：

- 窗口级有效关注定义；
- 眼部、头姿和面部行为特征；
- 注视与面部特征的时序融合模型；
- 独立的 PyTorch 训练环境与模型评测流程。

## 验收标准

- 一条命令能够读取 80 段序列并产生候选阈值汇总结果。
- 所有训练/测试切分按受试者隔离，测试受试者不参与阈值和判别临界值选择。
- 输出包含完整配置、每折选择结果、总体指标、按任务难度的结果和可用于论文的图表。
- 数据读取异常、缺失序列和非有限数值会产生明确错误，不会被静默跳过。
