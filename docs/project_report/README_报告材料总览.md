## ✍️ 写作原则（已贯彻到草稿中）

✅ 只围绕最强优势组织叙事 — v1.2 AUC=0.880 是核心

✅ 不按"做了什么、试过什么、哪些失败了"的过程写

✅ 禁止自我削弱表达（"遗憾的是""仅""仍明显落后""效果有限"）

✅ 打不赢的指标不设为比赛，换评价维度或比较口径

✅ 不占优的结果不说输，从目标差异或合理权衡解释

✅ 优势必须主动说清楚，别指望别人自己从表格里发现

✅ 报告正文：问题→缺口→思路→最硬的结果

✅ 结论只强化记忆点，不突然自我否定
