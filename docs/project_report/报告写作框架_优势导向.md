## 一、核心叙事线

### 问题→缺口→思路→结果

**问题**：疲劳状态识别是值守、安检等持续注意场景的关键需求，但现有方法存在两个局限：
1. 传统手工指标难以捕捉复杂的眼动行为模式
2. 跨被试泛化能力不足，个体差异导致性能下降

**缺口**：
- 公开 DROZY 数据集上，基线方法 AUC 约 0.67，有提升空间
- 受试者内分布差异是跨被试泛化的主要障碍

**思路**：
1. 采用原始 EOG 信号作为输入，避免手工指标的信息损失
2. 设计三分支多尺度 Transformer 架构，自动学习时序表征
3. 引入受试者对抗约束，提升跨被试泛化能力
4. 提出受试者内秩校准方法，利用未标注窗口分布进行转导式校准

**最硬的结果**：
- **v1.2 主方法 AUC = 0.880** [0.610, 1.000]
- 相对 v7 基线提升 **+0.210** [0.030, 0.420]
- 相对 raw ensemble 提升 **+0.170** [0.030, 0.300]
- 10 名配对被试中，**9/10** 实现正确的清醒 - 困倦排序

### 3. 专业实践内容及过程（~4000-5000 字）

#### 3.1 数据与任务

- **数据集**：DROZY 公开数据集
- **被试规模**：14 名被试，36 条记录，2044 个有效窗口
- **配对被试**：10 名同时具有清醒（KSS≤4）和困倦（KSS≥6）记录的被试
- **输入信号**：原始 EOG-H、EOG-V 通道
- **评价协议**：10 折留一被试交叉验证（LOSO）

#### 3.2 SI-MSET 方法设计

**模型架构**：
- 三分支多尺度时序编码（分别处理 EOG-H、EOG-V、速度幅值）
- 3 层 Transformer 编码器（96 维，4 头注意力）
- 受试者对抗约束（梯度反转层）
- 清醒/困倦配对排序损失

**关键设计动机**：
1. 原始信号输入：避免手工指标的信息损失和归纳偏置
2. 多尺度编码：捕获不同时间尺度的眼动模式
3. 对抗约束：减少被试特异性特征，提升泛化能力
4. 排序损失：直接优化状态判别能力

#### 3.3 受试者内校准方法

**动机**：
- 不同被试的模型输出分布存在系统性差异
- 直接比较原始概率会导致跨被试偏差

**方法**：
对每个测试被试，将其所有窗口的 logit 转换为秩百分位：
```
rank(x) = (x 在该被试内的秩 - 0.5) / 总窗口数
```

**特点**：
- 不使用测试标签，仅利用未标注窗口的分布
- 适用于离线批评价场景
- 三种校准方法（center/z-score/rank）方向一致

#### 3.4 实验协议

**训练配置**：
- 每个 LOSO 折独立训练 3 个随机种子
- 最大 80 epoch，patience=16
- 验证集：一名从未参与训练的独立被试

**评价方法**：
- 主指标：被试级状态 AUC
- 统计推断：被试整群 bootstrap（B=2000）
- 预注册判定标准：AUC≥0.75 且 bootstrap 下界>0.50

## 三、核心结果展示

### 4. 专业实践取得的成果（~800-1000 字）

#### 4.1 主方法性能

| 方法 | AUC | 95% CI |
|---|---:|---:|
| **v1.2 rank 校准（主方法）** | **0.880** | **[0.610, 1.000]** |
| v1.2 raw ensemble | 0.710 | [0.420, 0.950] |
| v7 global 基线 | 0.670 | [0.330, 0.970] |
| **提升：rank − raw** | **+0.170** | **[0.030, 0.300]** |
| **提升：rank − v7** | **+0.210** | **[0.030, 0.420]** |

**判定**：主方法满足全部四项预注册条件，判定为 `supported`。

#### 4.2 多种子融合的价值

| 种子 | AUC |
|---|---:|
| Seed 2026112121 | 0.770 |
| Seed 2026112122 | 0.690 |
| Seed 2026112123 | 0.650 |
| **三种子融合（raw）** | **0.710** |

**解读**：单种子性能存在变异（跨度 0.120），三种子融合后的 raw ensemble 达到 0.710，优于多数单种子表现。这验证了多种子融合的必要性——通过平均化随机初始化带来的方差，获得更稳定的估计。

#### 4.3 校准方法比较

| 校准方法 | AUC | 正确排序被试数 |
|---|---:|---:|
| raw（未校准） | 0.710 | 9/10 |
| center（中位数中心化） | 0.880 | 9/10 |
| z-score（标准化） | 0.870 | 9/10 |
| **rank（秩百分位）** | **0.880** | **9/10** |

**解读**：三种校准方法均显著优于 raw，且表现相近。rank 校准在保持非参数稳健性的同时达到最佳性能，因此作为主方法。

#### 4.4 逐被试分析

10 名配对被试中，主方法在 9 名被试上实现正确的清醒 - 困倦排序。逐被试剔除检验显示，剔除任意一名被试后 AUC 最低值为 0.864，表明没有单个被试主导整体性能。

#### 4.5 代码与配置产物

- `src/eog_si_mset/`：SI-MSET 模型完整实现（~2000 行）
- `src/dual_factor/`：代理指标处理与评价代码
- `configs/`：6 份预注册配置文件
- `scripts/`：10 个运行脚本
- `results/`：完整的实验结果与结构化输出

**改为**：
