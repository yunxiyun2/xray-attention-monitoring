# 岗位目标（模仿师兄风格）

根据公开 DROZY 数据集采集的双通道眼电信号，对疲劳状态下的眼动行为模式及时序特征变化规律进行分析，通过多尺度时序编码、Transformer 自注意力机制和受试者对抗约束，建立原始 EOG 信号与疲劳状态的映射关系，实现高精度的跨被试疲劳状态识别。

## 可选版本

### 版本 1（简洁版，最接近师兄风格）

> 根据公开 DROZY 数据集采集的双通道眼电信号，对疲劳状态下的眼动行为模式及时序特征变化规律进行分析，通过多尺度时序编码、Transformer 自注意力机制和受试者对抗约束，建立原始 EOG 信号与疲劳状态的映射关系，实现高精度的跨被试疲劳状态识别。

### 版本 2（强调方法创新）

> 根据公开 DROZY 数据集采集的双通道眼电信号，对疲劳状态下的眼动时序模式及个体差异特征进行分析，通过三分支多尺度编码、受试者不变 Transformer 和秩百分位校准方法，建立端到端的疲劳状态识别模型，实现留一被试交叉验证下 AUC 0.880 的分类性能。

### 版本 3（强调应用价值）

> 根据公开 DROZY 数据集采集的双通道眼电信号，对值守、安检等持续注意场景中的疲劳状态特征进行分析，通过深度学习自动提取时序判别特征并结合受试者内校准，建立可泛化的疲劳状态识别方法，为安全生产场景提供技术支撑。

## 如果需要更具体的技术细节

> 根据公开 DROZY 数据集采集的 EOG-H 和 EOG-V 双通道信号，对疲劳状态下的眼动时序模式及跨被试差异特征进行分析，通过 SI-MSET 模型（三分支多尺度编码 + 3 层 Transformer + 对抗约束 + 配对排序损失）和受试者内秩校准方法，建立原始眼电信号与清醒/困倦状态的映射关系，在 10 折留一被试交叉验证下实现 AUC 0.880 的分类性能。
