## 三、专业实践内容及过程

### 3.1 研究背景与需求分析

中国民航年旅客吞吐量已突破 8 亿人次，航空安全面临持续压力。历史数据分析表明，人为因素是导致重大航空安全事故的主要原因，占比达 83%。机场安检作为空防安全的核心关口，其有效性高度依赖于手检员持续稳定的警觉性与认知表现，对手检员疲劳状态进行多维度、高精度、个性化的监测，是遏制事故风险、保障绝对安全的刚性需求。

本研究的应用场景精准定位于现场安检通道的高清监控视频数据，一旦实现对手检员肢体关键点的运动行为模式疲劳检测，即可实现 24 小时无感、高精准的早期疲劳风险指数估计。然而，现有疲劳检测模型停留在对关键点时序轨迹的建模层面，如 ST-GCN、TCN 这类方法通常只关注单一个体局部区域的特征变化，忽略了对不同关键点之间的关联关系和跨个体的疲劳不变因素，因此在跨数据集验证中准确率下降幅度常超过 10%。

该瓶颈的根本原因在于现有骨架建模存在个性化和不变性的矛盾。主流时空图卷积网络（ST-GCN 类方法）通过统一的拓扑邻接矩阵建模动作序列，强调时序平滑与全局一致性，但忽略了不同个体在身体比例、运动幅度及疲劳表现上的差异，导致学习到的特征高度个体化、泛化性弱；而对比学习类方法（如 S-ALE）虽尝试对齐个体间特征分布，却牺牲了关键点之间的协同信息。两者在"跨个体不变特征"与"关键点互补性"之间缺乏平衡机制，无法同时保证个体差异的解耦与群体层面的稳定表征。

这一瓶颈直接导致在真实环境下模型往往只能在单一主体或受控场景中维持高准确率，而在多对象、长时监测条件下，预警准确率下降显著，误报率超过 20%、漏报率 15% 以上。解决此瓶颈的难度极高，要求模型在高维的人体运动关键点时空空间中，同时捕捉跨个体不变规律与局部关键点间的动态互补关系，在个体差异、姿态噪声与时序不稳定的多重干扰下仍能保持一致表征。

### 3.2 研究思路与技术路线

针对上述问题，本研究提出以下解决思路：在肢体关键点的时空特征学习中，引入关键点互补性注意力机制以建模不同关节的协同作用，并通过特征解耦约束区分个体差异与群体共性，可在潜空间中形成稳定的跨对象不变疲劳子空间，从而实现群体层面一致的疲劳表征。

该思路基于不同个体在疲劳状态下动作变化具有共性的观察。通过正交约束可将共性特征与个体特征分离，提取出群体共享的疲劳模式；而互补性注意力机制则能在局部关键点缺失时自动利用其他部位的信息进行补偿，从原理上提升模型的泛化性与鲁棒性。前期实验结果表明，在 ST-GCN 框架中加入跨关键点注意力与特征解耦约束后，模型在 NTHU-DDD 数据集的跨主体测试中 F1 分数提升约 6%。

本研究摒弃了"个体特征或群体特征"的二元对立范式，提出了"个体差异解耦和群体共性建模"的统一范式。与传统方法仅在特征层后期对齐或简单加权融合不同，本研究在时空图网络引入关键点互补性注意力与特征正交约束的协同优化，实现跨个体不变性与关键点互补性的深度耦合。若本研究的猜想被证实，将首次在疲劳检测任务中实现跨对象不变特征与关键点互补机制的统一建模，这不仅是对时空图网络结构的改进，更是对现有"个体依赖型"疲劳识别范式的根本性颠覆。

### 3.3 数据与评价协议

本研究使用两个公开疲劳检测数据集进行验证。NTHU-DDD 数据集是疲劳检测领域的标准基准，包含多主体、多场景的驾驶疲劳视频数据，涵盖不同光照条件、姿态变化和个体差异。ASD 数据集则专注于机场安检场景，包含手检员在真实工作环境和模拟工作场景下的行为视频，为研究提供了贴近实际应用的数据基础。

评价协议采用跨主体交叉验证，按身份划分训练集和测试集，确保测试主体不出现在训练集中，以验证模型的跨个体泛化能力。主指标包括准确率、精确率、召回率、F1 分数和 AUC，同时报告跨主体测试中的性能方差以评估稳定性。统计推断采用 bootstrap 方法，从测试主体中有放回抽样，重复 2000 次得到 bootstrap 分布，计算 95% 置信区间。

### 3.4 PEFM 模型设计

基于上述思路，本研究提出 PEFM（Pose Equivariant Fatigue Modeling）框架，其核心设计包括三个关键部分。第一部分是关键点互补性注意力模块（CAM），该模块通过建模不同关节之间的协同关系，在局部关键点缺失或噪声干扰时自动利用其他部位的信息进行补偿。具体而言，对每个关键点计算其与其他所有关键点的注意力权重，形成互补性注意力矩阵，使模型能够动态调整对不同身体部位的依赖程度。

第二部分是特征解耦正交约束模块（DOA），该模块通过正交约束将潜空间特征分解为个体差异子空间和群体共性子空间。个体差异子空间捕获与特定主体相关的特征，如身体比例、动作习惯等；群体共性子空间则捕获跨主体共享的疲劳模式，如动作迟缓、姿态协调性下降等。通过最大化两个子空间的正交性，模型能够学习到与个体无关的通用疲劳表征。

第三部分是时空一致性建模模块，该模块在时间维度上捕捉疲劳状态的动态演变过程。疲劳不是瞬时状态，而是一个渐进累积的过程，表现为动作延时性增加、姿态协调性下降、运动幅度减小等时序特征。本模块通过时序卷积和注意力机制，建模疲劳状态在时间维度上的连续性和一致性，提升模型对疲劳过程的感知能力。

### 3.5 实验配置与训练细节

训练配置方面，模型基于 PyTorch 框架和 OpenMMLab 工具包实现，使用 RTX 3090 GPU 进行训练。输入为人体关键点序列，包括 17 个身体关节点的二维或三维坐标，序列长度设为 100 帧，采样率为 25fps。模型维度设为 256，图卷积层数为 4 层，注意力头数为 8 个。最大训练 epoch 为 100，早停 patience 设为 10，batch size 为 32。优化器采用 AdamW，初始学习率为 0.001，采用余弦退火策略进行学习率调整。

评价方面，采用留一主体交叉验证（LOSO），每折使用除一名主体外的所有数据训练，剩余主体的数据用于测试。为评估模型的跨数据集泛化能力，还进行了跨数据集测试，即在一个数据集上训练，在另一个数据集上测试。消融实验逐一移除或替换 PEFM 中的关键模块（互补性注意力模块 CAM、特征解耦正交约束 DOA），观察各维度指标的变化，以排他性验证各组件的必要性与贡献度。对比实验与当前最强基线模型（ST-GCN、PoseC3D、CTR-GCN、TGCN）在相同数据和实验设置下进行横向比较，验证本模型在跨个体不变性和时空建模能力上的优势。

### 3.6 预期成果与技术指标

本研究预期在跨主体疲劳检测任务中实现显著性能跃升。在 NTHU-DDD 与 ASD 数据集上，跨对象检测准确率预期提升超过 6%，F1 分数预期提升约 8%。这些改进使模型在复杂场景下的疲劳识别精度恢复至接近理想条件的 90% 以上，验证了该框架在不变性与鲁棒性建模方面的实质突破。

本研究的核心结论为："在时空图网络中引入关键点互补性建模与特征解耦正交约束，能显著提升疲劳检测模型的跨个体不变性并进而提升在复杂场景下的检测精度与稳定性。"该结论具体、可量化，且能够通过跨主体实验与消融对比被实验证伪。验证体系包括三个正交且完备的验证维度：跨个体不变性（模型是否能在不同个体之间保持稳定的特征表示与分类性能）、关键点互补性（模型是否能在多部位特征不一致时保持全局稳定性）、时空一致性（模型是否在时间维度上有效捕捉疲劳动态特征）。
