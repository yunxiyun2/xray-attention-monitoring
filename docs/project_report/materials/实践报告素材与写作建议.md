## 2. 学校要求与师兄写法要分清

学校模板要求总结报告一般不少于5000字，正文栏目为：专业实践目标、专业实践岗位介绍与安排、专业实践内容及过程、专业实践取得的成果。没有在这些材料中发现最低图表数量、模型精度或必须发表论文的要求。

总结报告模板还要求签字手写、A3双面骑马钉装订、一式两份；考核表则要求A4双面、一式两份，两份材料的打印要求不同。2024级通知要求第三学期开始、第五学期完成考核，实践时长不少于一年。实际提交时间应结合本次学院通知核实，不照抄师兄填表日期。

师兄报告的布局：第1—2页封面及说明，第3—4页目标、岗位职责和时间安排，第5—13页两条技术研究线的方法、图表和实验，第14—15页实践过程与成果，第16—17页导师和学院评价。正文包含6个编号图、5个编号表。值得借鉴的是“需求—问题—方法—验证—成果”的连贯结构；其两条模型研究线、GPU配置、精度提升、论文成果均不适用于直接移植。

## 3. 当前项目实际到了哪里

旧X-ray分类与多模态模型仍保留在仓库，但已归档。当前研究主线是DROZY上的疲劳相关EOG代理指标处理、候选双因子结构检验和增量预测效度分析。README顶部已指向v7；方向锁定文档保留v5历史入口，不能用它们代替v6/v7结果判断当前进展。

| 事项 | 核对结果 | 报告如何呈现 |
|---|---|---|
| 数据规模 | 14名被试、36条记录；2088个生成窗口、2044个有效窗口 | 数据处理规模，不写成2044名独立样本 |
| v6候选结构 | F1：FD/PSV/SA/FN；F2：SE/GTE/SV，4/3共7项 | 候选分组，不是已发现的疲劳机制 |
| 模拟校准 | 7类场景，每类200组；强双因子和非正态双因子接受200/200，其余5类接受0/200 | 限定为设定模拟条件下的检验表现 |
| 平行分析 | 七指标三个非重叠相位均建议2个维度 | 维数线索，不等于两因子模型成立 |
| 真实双因子PAF | 三相位均出现Heywood问题；C5为not_evaluable | 保留失败及不可评估状态，不展示虚构载荷 |
| 配对方向效度 | 10名配对被试，7项Holm校正后均不显著 | 估计差值与区间，结论不确定；不推断“没有效应” |
| v6结构决策 | B，L0；teacher_accepted=false | 当前证据不足以支持候选结构，不称教师已验收 |
| v7增量预测 | global AUC 0.670；双分数0.520；ΔAUC −0.150，95% CI [−0.470, 0.140]；`inconclusive` | 未显示增量，不说双分数提高预测 |
| 测量验证 | 原始事件/代理指标效度未运行 | 不宣称已经验证真实注视空间、绝对扫视角度或生理机制 |
| 后续阶段 | 预测效度已运行；CFA、外部数据与不变性未运行 | 历史诊断代码和文件不等于当前版本通过 |

这条实践链有真实工作量：数据与口径审计、事件与窗口处理、统计估计实现、整人重采样、模拟正负对照、结构化结果及可追溯报告。科学假设未获得支持可以如实报告；它并不能自动保证实践考核或学位论文通过。

## 5. 建议的报告主线与篇幅

候选题目：**《面向疲劳状态分析的眼电代理指标处理与统计验证实践》**。正式题目及内容须与已审批的实践计划、岗位和实际职责一致；若实践计划涵盖早期X-ray任务，可交代需求与方案演进，分别标明各阶段成果，避免把归档结果当作当前模型结论。

建议正文约6000—7500字，按学校四栏组织：

1. **实践目标，约600字**：任务需求、输入数据、希望解决的问题、可交付成果，以及当前验证边界。
2. **岗位介绍与安排，约700字**：本人真实职责、协作方式、环境和按实际记录整理的阶段安排。单位、导师和时间不能根据Git提交时间推断。
3. **内容及过程，约4000—5000字**：需求与文献梳理；数据字典和质量控制；EOG代理指标与窗口处理；v5方法问题定位及v6修正；已知真值模拟；真实数据结构和配对效度检验；v7被试留一增量预测；问题、解决措施与尚存限制。将五张实证图与两张设计图放在相应讨论旁。
4. **取得的成果，约800—1000字**：代码与配置、审计产物、模拟证书、正式运行结果、复现与报告机制、个人工程能力提升和未完成事项。论文投稿、专利、上线部署等只有确有证据才填写。

适合配套的表：八项原始指标定义与单位/代理边界表；数据质量与各分析样本量表；v5/v6更改及验证对照表；模拟结果表；真实数据各验收门状态表。表格不必全放，以避免同一结果反复展示。

## 6. 补实验应服务于具体问题

v7已经完成当前矩阵可支持的核心增量预测检验。正式报告应优先整理已有结果；若后续科研需要补充实证，应基于新问题另立 SPEC，不为增加图数重新搜索指标：

- **模拟难度与检出能力边界**：预先固定几档载荷强度及SE/GTE冗余程度，保持14人/36记录和现有门槛，统计收敛、Heywood和接受率并给出二项比例区间。回答“强正对照通过后，较弱或冗余结构下表现如何”。先制定新协议及运行预算；这是后续建议，本次未执行。
- **矩阵层级的描述性审计**：按被试、记录和KSS统计数据覆盖，解释10名配对被试的来源；固定当前七指标，以现有结果绘制相关/协方差分解。不能从特征矩阵测试网格粒度、事件阈值或滤波参数敏感性，这些需要原始数据。

以上诊断不解锁CFA，不产生新的A判定，也不替代原始代理指标测量验证。当前规范已约束继续试删；任何新的结构方案须另有理论依据、独立验证安排及新SPEC。

## 7. 写正式报告前应修正或注明的口径

1. “4/2一定不可识别”“3指标大于2因子所以可识别”不是一般成立的识别判据；识别取决于整体模型、约束和参数。现有模拟与PAF失败不能替代识别证明。
2. 模拟通过只覆盖设定条件；不能由此断言真实数据失败完全是数据原因、算法实现完全无误。SE/GTE高相关是重要线索，尚不能单独确认为唯一根因。
3. `measurement_diagnostics.json`明确GTE实现为相邻网格对的联合熵，不应直接称为条件转移熵或因果意义的transfer entropy；指标定义应与实现一致。
4. PSV代码定义是扫视峰值速度均值；v6最终汇报开头写成“注视稳定性方差”有误。FN实现是单位时间注视事件频率，不是未归一化次数。
5. v6的SV选取参考了同一数据集此前相关结构，属于数据引导的探索性修正，不写成完全独立预注册确认。
6. 真实运行的bootstrap结构汇总是`not_evaluable`，不能把配置的B=2000说成成功完成2000个有效模型重采样。
7. 本次只读核对发现：当前代码总SHA256与11月15日模拟证书不一致，配置SHA256一致。近期报告脚本改动也被总哈希包含。历史结果仍按原运行记录引用；当前代码不能直接声称持有匹配证书，重新正式验收前需核对来源快照和变化范围。

老师反馈要求把结构、跨被试稳定性与构念效度分别交代。实践报告可以展示已经完成的处理和验证工作，同时明确科学判定未通过；不能用工程产物数量替代科学假设成立。
