## 1. 研究任务

### 1.1 题目

**基于眼电代理指标的眼动行为表征与疲劳状态区分研究**

### 1.2 任务背景

疲劳会改变值守、安检等持续注意任务中的眼动行为，但“疲劳”本身不可直接观测。现有系统通常将多项眼动或眼电指标压成单一疲劳分数，难以说明该分数包含哪些行为成分，也难以判断不同成分是否提供互补信息。本项目研究在仅有 EOG 通道的公开 DROZY 数据集上，可以构造哪些可解释的眼动代理指标，这些指标是否支持“驱动衰减”和“分布—转移共变”两个候选成分，以及预定义的双成分分数能否比单一疲劳总分更有效地区分清醒和困倦状态。

### 1.3 研究问题

本任务围绕同一个可证伪问题展开：

> 在 DROZY 的眼电代理指标中，能否获得稳定的双成分行为结构，并使该双成分比单一疲劳总分提供可重复的增量状态判别能力？

该问题分解为三个顺序阶段：

1. **表征是否可计算**：由 EOG-H/EOG-V 构造注视、扫视、空间分布和转移统计指标，并形成可审计的窗口特征矩阵。
2. **结构是否可验证**：检验预定义的 FD/PSV/SA/FN 与 SE/GTE/SV 候选分组能否通过独立 EFA 结构检查。
3. **结构主张是否有增量价值**：即使不把探索性结构当成潜因子结论，也检验预先定义的 F1、F2 分数是否比单一 fatigue score 提高被试级清醒/困倦判别能力。

### 1.4 可证伪假设

- H1：预定义的眼电代理指标能够构造可复现的被试内行为特征。
- H2：候选指标支持稳定的两成分结构。
- H3：双成分模型相对单一疲劳总分具有正向增量 AUC。

H1 是工程和数据前提；H2、H3 是科学假设。任何一项不满足，都必须在结论中如实保留。

## 2. 数据与研究对象

- 数据集：公开 DROZY 数据集。
- 输入信号：EOG-H、EOG-V。
- 数据规模：14 名被试、36 条可用记录、2088 个候选窗口、2044 个有效完整窗口。
- 窗口划分：30 秒窗、10 秒步长；结构检验采用 phase 0 非重叠窗口，避免把重叠窗口当作独立样本。
- 状态标签：记录级 KSS。KSS ≤ 4 定义为清醒，KSS ≥ 6 定义为困倦，KSS=5 不用于二分类。
- 配对预测样本：10 名同时具有清醒和困倦记录的配对被试。其余 4 人因只有单侧状态被排除。
- 研究单位：被试。窗口只用于在同一记录或被试内部形成特征，不把 2044 个窗口宣称为 2044 名独立样本。

## 3. 指标与分析路线

### 3.1 七项候选指标

| 指标 | 含义 | 方向假设 |
|---|---|---|
| FD | 平均注视时长 | 困倦时增加 |
| PSV | 扫视峰值速度均值 | 困倦时降低 |
| SA | 扫视幅度均值 | 困倦时降低 |
| FN | 单位时间注视事件频率 | 困倦时降低 |
| SE | 注视点在空间网格中的分布熵 | 困倦时增加 |
| GTE | 相邻网格对 `(current, next)` 的联合熵 | 困倦时增加 |
| SV | 注视点二维协方差矩阵的迹 | 困倦时增加 |

F1 定义为 `FD↑、PSV↓、SA↓、FN↓` 的等权平均，F2 定义为 `SE↑、GTE↑、SV↑` 的等权平均，global 为 F1、F2 的等权平均。方向在分析前固定，不根据 AUC 结果翻转。

### 3.2 EFA 结构检查

采用预注册主轴因子分析（PAF）、被试均衡相关、整人 cluster bootstrap 和三个非重叠相位。结构判定要求载荷、交叉载荷、共同方差、因子相关、被试级稳定性及模型收敛同时满足门槛。失败时保留 Heywood case、不收敛和 `not_evaluable`，不通过放宽阈值修补结果。

### 3.3 增量预测效度

在 10 名配对被试上进行被试级留一交叉验证。每折的标准化器与 L2 逻辑回归只用其他 9 人训练，同一被试的清醒与困倦记录同时留出。固定比较 global、F1-only、F2-only、F1+F2 和七指标模型。主判定为：

```text
ΔAUC = AUC(F1+F2) - AUC(global)
```

只有 `ΔAUC ≥ 0.05` 且被试整群 bootstrap 95% 下界大于 0，才判定双成分具有增量价值。其他情况按预注册规则判为 `inconclusive` 或 `global_better`；不得根据结果改名、翻转方向或继续试删。

## 4. 研究过程

1. **数据读取与质量控制**：核对 EDF 通道、KSS、采样率、记录缺失和窗口完整性；剔除无效窗口，但不回填、不重叠抽样。
2. **眼动事件与指标构建**：完成 EOG 带通滤波、Hampel 去伪迹、I-VT 事件检测、窗口特征计算和被试内标准化。
3. **结构检验**：比较八指标、七指标和 F1 子集在两个或三个因子下的 PAF 解，并执行三相位平行分析、整人 bootstrap 与稳定性检查。
4. **方法复盘**：修正历史代码中的非迭代主成分冒充实 PAF、均值退化、重叠窗口泄漏、非标准化载荷和错误识别表述。
5. **预测效度检验**：用固定 F1/F2/global 分数完成 10 折被试留一预测、AUC/AP/Brier/log-loss 计算和 2000 次整群 bootstrap。
6. **结果沉淀**：保存配置、输入哈希、代码哈希、逐折预测、bootstrap 样本、判定文件、报告和图件。

## 5. 研究结果

### 5.1 结构与稳定性

- 七项指标在三个非重叠相位的平行分析中均建议二维结构，这是维数线索。
- v6 真实数据的二因子 PAF 在所有相位均出现 Heywood 问题，cluster bootstrap 汇总为 `not_evaluable`。
- 因而 H2 未通过：在当前指标和数据条件下，不能宣称稳定的双因子结构成立。
- SE 与 GTE 的加权相关约为 0.899，说明“分布—转移”候选组存在明显冗余；该事实可用于解释估计困难，但不足以单独证明唯一根因。

### 5.2 增量预测效度

主运行目录：`results/dual_factor_predictive_v7/20261121T042129Z-70784213`。

| 模型 | 被试留一 AUC | 被试整群 bootstrap 95% CI |
|---|---:|---:|
| 单一疲劳总分 global | 0.670 | [0.330, 0.970] |
| F1 only | 0.640 | [0.300, 0.970] |
| F2 only | 0.010 | [0.000, 0.090] |
| F1+F2 | 0.520 | [0.180, 0.880] |
| 七指标堆叠 | 0.700 | [0.350, 1.000] |
| **F1+F2 − global** | **−0.150** | **[−0.470, 0.140]** |

v7 按预注册规则判定为 `inconclusive`。点估计没有显示增量，置信区间覆盖零；因此既不能写“双成分提高预测”，也不能把“没有显著差异”写成“两种模型完全等价”。

F2-only 在外样本预测中的 AUC 为 0.010，但原始预定义 F2 分数的描述性 AUC 约为 0.48，逐被试 F2 配对正方向为 6/10。该反差主要反映小样本、逐折系数方向不稳定和跨被试差异，不能据此宣称 F2 已被稳定证明为反向指标。七指标堆叠的 0.700 也只作为高容量参考，不能反向证明潜因子结构。

### 5.3 研究任务完成情况

| 任务 | 判定 | 证据 |
|---|---|---|
| 建立可审计的 EOG 代理指标处理链 | 完成 | 2088→2044 窗口审计、矩阵与运行指纹 |
| 检验候选双成分结构 | 完成，不支持 | v6 `Decision B`、PAF Heywood、C5 `not_evaluable` |
| 检验双成分增量预测价值 | 完成，不确定 | ΔAUC −0.150，95% CI [−0.470, 0.140] |
| 判断能否形成可靠疲劳分类器 | 不能支持 | n=10，单分数 AUC 0.670 且 CI 很宽 |
| 外部数据集与多群组不变性 | 本任务范围外 | 未执行，不写入已取得成果 |

## 6. 最终结论

本实践完成了一个闭环的眼动行为表征与效度研究：从 EOG 数据质量控制、指标构造、候选结构检验，到被试级增量预测验证。结果显示，现有指标具有有限的单维清醒/困倦区分信号，但未观察到稳定的“驱动衰减—分布转移”双因子结构，也没有发现双成分相对于单一疲劳总分的增量预测价值。因此，在本数据规模、EOG 代理测量和预注册分析条件下，**双因子可分离且具有增量价值的研究假设未获支持**。

该结论不是“双因子必然不存在”，而是当前数据与测量方式不足以支持它。实践成果应定位为可复现的方法学与负结果：明确测量边界、避免数据泄漏、保留失败证据，并给出后续需要外部数据或独立测量验证的条件。

## 7. 可直接写入实践报告的摘要

本研究面向持续注意场景中的疲劳状态识别问题，基于 DROZY 数据集的 EOG 信号构建注视、扫视、空间分布和转移统计等七项眼动代理指标。研究先检验“驱动衰减”与“分布—转移共变”两成分候选结构，再通过被试级留一交叉验证评估双成分分数相对单一疲劳总分的增量预测价值。在 14 名被试、36 条记录、2044 个有效窗口中，10 名被试具有可配对的清醒和困倦记录。预注册主轴因子分析未能稳定估计二因子模型，候选双成分结构未获支持；预测分析中，单一总分 AUC 为 0.670，双成分模型 AUC 为 0.520，差值 `−0.150`，95% CI `[−0.470, 0.140]`，未显示显著增量。研究最终形成可复现的数据审计、特征构造、结构检验和预测评估流程，并得出当前 EOG 代理指标不足以支持双因子疲劳表征的可证伪结论，为后续独立测量效度和外部数据验证划定了边界。

2. 不能写“发现双因子”“双因子可分离成立”“双因子提高准确率”。可写“候选结构未获支持”“增量价值不确定”。

4. PAF 的 Heywood case 是结构估计失败证据，不是“已经证明数据中不存在任何二维关系”。
5. 实践成果不以高 AUC 为前提；完成的工具链、审计过程和可复现负结果同样属于工程实践成果。
