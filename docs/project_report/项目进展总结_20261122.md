## 一、研究任务总览

### 1.1 项目名称
**基于眼电代理指标的眼动行为表征与疲劳状态区分研究**

### 1.2 核心问题
在仅有 EOG 通道的公开 DROZY 数据集上：
1. 能否构造可解释的眼动代理指标，形成可审计的窗口特征矩阵？
2. 这些指标是否支持"驱动衰减"和"分布—转移共变"两个候选成分？
3. 预定义的双成分分数能否比单一疲劳总分更有效地区分清醒和困倦状态？

### 1.3 研究路线演进

| 阶段 | 方法 | 核心任务 | 状态 |
|---|---|---|---|
| **v5** | 候选双因子 EFA | 方法修正：非迭代 PCA→PAF、重叠窗口→非重叠、均值退化→标准化 | 完成，模拟校准通过 |
| **v6** | 真实数据 EFA | 结构检验：七指标三相位平行分析、整人 bootstrap | Decision B，`not_evaluable` |
| **v7** | 增量预测效度 | 被试留一交叉验证：双成分 vs 单一总分 | `inconclusive`，ΔAUC = −0.150 |
| **v1** | SI-MSET 深度模型 | 原始 EOG 输入、Transformer 编码、对抗约束 | AUC = 0.750，`inconclusive` |
| **v1.1** | 模型扩容 | 增加层数、维度、epoch | AUC = 0.720，`inconclusive` |
| **v1.2** | 多种子融合 + 校准 | 3 seed ensemble + 被试内秩校准 | **AUC = 0.880，`supported`** |

## 二、已完成的核心成果

### 2.1 数据与特征工程（v5–v7）

**输入数据**：
- DROZY 公开数据集，14 名被试，36 条可用记录
- 原始信号：EOG-H（水平）、EOG-V（垂直）
- 状态标签：记录级 KSS（KSS ≤ 4 清醒，KSS ≥ 6 困倦）

**窗口划分**：
- 30 秒窗、10 秒步长
- 2088 个候选窗口 → 2044 个有效完整窗口（质量控制后）
- 结构检验采用 phase 0 非重叠窗口（706 个），避免重叠抽样泄漏

**七项候选指标**：

| 指标 | 含义 | 单位 | 疲劳方向假设 |
|---|---|---|---|
| FD | 平均注视时长 | 秒 | 困倦时增加 ↑ |
| PSV | 扫视峰值速度均值 | °/s | 困倦时降低 ↓ |
| SA | 扫视幅度均值 | ° | 困倦时降低 ↓ |
| FN | 单位时间注视事件频率 | Hz | 困倦时降低 ↓ |
| SE | 注视点空间分布熵 | bits | 困倦时增加 ↑ |
| GTE | 相邻网格联合熵 | bits | 困倦时增加 ↑ |
| SV | 注视点协方差迹 | deg² | 困倦时增加 ↑ |

**预定义分数**：
- F1 = (FD↑ + PSV↓ + SA↓ + FN↓) / 4（驱动衰减因子）
- F2 = (SE↑ + GTE↑ + SV↑) / 3（分布—转移因子）
- global = (F1 + F2) / 2（全局疲劳分数）

### 2.2 结构检验结果（v6）

**平行分析**：
- 七指标在三个非重叠相位均建议 2 个维度（维数线索）
- 但平行分析仅提示维度数量，不证明因子模型成立

**真实数据 PAF 估计**：
- 二因子模型在所有三个相位均出现 Heywood case（方差估计为负或载荷>1）
- 整人 cluster bootstrap 汇总为 `not_evaluable`
- SE 与 GTE 的加权相关约 0.899，显示候选组内存在明显冗余

**结论**：H2 未通过——在当前指标和数据条件下，不能宣称稳定的双因子结构成立

### 2.3 增量预测效度（v7）

**设计**：
- 10 名同时具有清醒和困倦记录的配对被试
- 被试级留一交叉验证（LOSO）：每折用 9 人训练标准化器和 L2 逻辑回归
- 固定比较 global、F1-only、F2-only、F1+F2 和七指标堆叠

**主结果**：

| 模型 | AUC | 95% CI |
|---|---:|---:|
| 单一疲劳总分 global | 0.670 | [0.330, 0.970] |
| F1 only | 0.640 | [0.300, 0.970] |
| F2 only | 0.010 | [0.000, 0.090] |
| F1+F2 | 0.520 | [0.180, 0.880] |
| 七指标堆叠 | 0.700 | [0.350, 1.000] |
| **F1+F2 − global** | **−0.150** | **[−0.470, 0.140]** |

**判定**：`inconclusive`——双成分未显示增量价值，置信区间覆盖零

### 2.4 深度模型 SI-MSET（v1–v1.2）

**动机**：
- 代理指标路线未能验证稳定结构，预测 AUC 也有限（0.670）
- 转向原始 EOG 信号，用深度学习自动学习时序表征
- 引入受试者对抗约束和配对排序损失，提升跨被试泛化

**模型架构**：
- 输入：原始 EOG-H、EOG-V 和速度幅值（三分支）
- 编码：多尺度时序卷积 + 3 层 Transformer（96 维，4 头）
- 约束：受试者对抗分类（梯度反转）、清醒/困倦配对排序损失
- 评价：10 折 LOSO，测试被试完全不参与训练或早停

**v1.2 协议**：
- 每个 LOSO 折独立训练 3 个随机种子
- 融合三个 seed 的窗口 logit
- 对比四种校准方法：raw、center、z-score、rank
- 主方法：three-seed ensemble + subject rank calibration

**主结果**：

| 指标 | 结果 |
|---|---:|
| 单 seed AUC（3 个） | 0.770 / 0.690 / 0.650 |
| three-seed raw ensemble | 0.710 |
| center calibration | 0.880 |
| z-score calibration | 0.870 |
| **rank calibration（主方法）** | **0.880** |
| 主方法 bootstrap 95% CI | [0.610, 1.000] |
| rank − raw ΔAUC | +0.170 [0.030, 0.300] |
| rank − v7 global ΔAUC | +0.210 [0.030, 0.420] |

**判定**：`supported`——四项预注册条件均满足

**关键说明**：
1. 三个单 seed AUC 跨度 0.120，融合后 raw 为 0.710，低于最佳单 seed
2. 校准只使用测试被试的窗口分数分布（不读取标签），适用于离线批评价
3. 10 名配对被试中，主方法保持 9/10 的清醒—困倦排序正确
4. 置信区间仍宽（0.610–1.000），相对两个基线的下界都只有 0.030

## 三、可证伪假设与最终结论

### 3.1 假设检验状态

| 假设 | 内容 | 判定 | 证据 |
|---|---|---|---|
| H1 | 预定义眼电代理指标能构造可复现的被试内行为特征 | **通过** | 2088→2044 窗口审计、矩阵与运行指纹 |
| H2 | 候选指标支持稳定的两成分结构 | **不通过** | v6 Decision B、PAF Heywood、C5 `not_evaluable` |
| H3 | 双成分模型相对单一疲劳总分具有正向增量 AUC | **不确定** | ΔAUC −0.150，95% CI [−0.470, 0.140] |
| H4 | SI-MSET 在 LOSO 下达到 AUC ≥ 0.75 | **通过（有条件）** | v1.2 rank 校准 AUC = 0.880，但单 seed 不稳定 |

### 3.2 最终结论

1. **代理指标路线**：成功构建了可审计的 EOG 代理指标处理链，但候选双因子结构在真实数据中未能稳定估计，增量预测价值也未获支持。这是**可复现的负结果**，明确了当前测量方式的边界。

2. **深度模型路线**：SI-MSET v1.2 在受试者内校准条件下达到了 0.880 的 AUC，但单 seed 稳定性有限（0.650–0.770），且校准方法依赖整段未标注窗口的离线批处理，不能直接用于单窗口实时预测。

3. **总体定位**：本项目完成了从指标构造、结构检验到预测验证的完整闭环，形成了可复现的方法学成果和负结果证据。科学假设未获支持不等于工程实践失败——数据审计、特征构造、统计估计、整人重采样、模拟正负对照、结构化结果及可追溯报告均属于实践成果。
