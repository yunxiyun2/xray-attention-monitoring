## 一、专业实践目标

疲劳状态识别是值守、安检、交通等持续注意场景中的关键需求。传统方法依赖手工设计的眼动指标，将多指标压缩为单一疲劳分数。然而，这种方法存在两个主要局限：第一，手工指标难以捕捉眼动信号中的复杂时序模式和多尺度特征；第二，不同被试的基线眼动行为存在显著个体差异，导致模型在新被试上性能下降。

公开 DROZY 数据集为疲劳状态识别研究提供了标准基准，但现有方法在留一被试交叉验证（LOSO）协议下的 AUC 约 0.67，有较大提升空间。基于上述背景，本次专业实践的目标是：

1. **构建端到端的疲劳分类器**：直接从原始 EOG 信号学习时序表征，避免手工指标的信息损失和归纳偏置；
2. **提升跨被试泛化能力**：通过受试者对抗约束和受试者内校准方法，减少个体差异对性能的影响；
3. **达到预注册的性能目标**：在 10 折留一被试交叉验证下，AUC ≥ 0.75；
4. **形成可复现的研究产物**：包括完整的模型实现、训练代码、实验结果和复现材料。

## 三、专业实践内容及过程

### 3.1 问题定义与研究缺口

**问题定义**：给定一段 EOG 信号，判断被试处于清醒还是困倦状态。形式化为二分类问题，输入为 30 秒的 EOG 窗口，输出为疲劳状态概率。

**现有方法的局限**：

1. **特征工程局限**：现有方法依赖手工设计的眼动指标（如 FD、PSV、SA 等），这些指标需要预定义事件检测算法（如 I-VT），且可能丢失原始信号中的判别信息。

2. **跨被试泛化**：不同被试的眼动行为存在显著的基线差异（如有些人天生眨眼频率高），直接比较原始概率会导致跨被试偏差。留一被试交叉验证（LOSO）是评价泛化能力的标准协议，但现有方法在该协议下 AUC 约 0.67。

3. **数据规模限制**：DROZY 数据集包含 14 名被试、36 条记录，属于小样本场景，对模型的泛化能力提出更高要求。

**核心思路**：采用原始 EOG 信号作为输入，通过深度学习自动学习时序表征，并引入受试者对抗约束和受试者内校准方法提升跨被试泛化能力。

### 3.2 数据与任务

**数据集**：DROZY 公开数据集

| 统计项 | 数值 |
|--------|------|
| 被试数 | 14 |
| 记录数 | 36 |
| 有效窗口数 | 2044 |
| 配对被试数（清醒 + 困倦） | 10 |

**输入信号**：
- EOG-H（水平通道）
- EOG-V（垂直通道）
- 速度幅值（由 EOG-H 和 EOG-V 计算得到）

**窗口划分**：
- 窗口长度：30 秒
- 步长：10 秒（相邻窗口有 20 秒重叠）
- 评价时采用非重叠窗口，避免数据泄漏

**状态标签**：
- 清醒：KSS ≤ 4
- 困倦：KSS ≥ 6
- KSS = 5 为中间状态，不用于二分类

**评价协议**：
- 10 折留一被试交叉验证（LOSO）
- 每折使用 9 名被试训练，1 名被试测试
- 测试被试完全不参与训练或早停决策

### 3.3 SI-MSET 方法设计

#### 3.3.1 模型架构

SI-MSET（Subject-Invariant Multi-Scale EOG Transformer）的核心设计包括四个部分：

**（1）三分支多尺度时序编码**

三个输入分支分别处理 EOG-H、EOG-V 和速度幅值。每个分支采用多尺度时序卷积，捕获不同时间尺度的眼动模式：短尺度捕捉快速变化（如扫视），中尺度捕捉中等长度的模式（如注视 - 扫视序列），长尺度捕捉慢速趋势（如疲劳累积）。

**（2）Transformer 编码器**

编码后的特征送入 3 层 Transformer 编码器（96 维，4 头注意力），进行全局依赖建模。Transformer 的自注意力机制能够捕捉长距离时序依赖，适合建模眼动信号的动态变化。

**（3）受试者对抗约束**

为减少被试特异性特征，引入梯度反转层（Gradient Reversal Layer）进行受试者对抗训练：主任务为疲劳状态分类，对抗任务为预测被试 ID。通过最大化被试 ID 预测误差，模型学习到与个体无关的通用特征表示。

**（4）配对排序损失**

传统的交叉熵损失独立处理每个样本，忽略了同一被试内清醒和困倦窗口的相对关系。本研究引入配对排序损失：对于每个被试，随机采样清醒 - 困倦窗口对，要求清醒窗口的疲劳分数低于困倦窗口，直接优化状态排序能力。

#### 3.3.2 关键设计动机

1. **原始信号输入**：避免手工指标的信息损失和归纳偏置，让模型自动学习判别特征。

2. **多尺度编码**：眼动事件发生在不同时间尺度（扫视：几十毫秒；注视：几百毫秒；疲劳趋势：几分钟），多尺度设计能够同时捕获这些模式。

3. **对抗约束**：不同被试的基线眼动行为差异很大（如有些人天生眨眼频率高），对抗约束迫使模型忽略个体特异性特征，专注于与疲劳相关的通用模式。

4. **排序损失**：疲劳是一个相对概念，同一被试的清醒和困倦状态可以配对比较。排序损失直接优化这种相对判别能力。

### 3.4 受试者内校准方法

#### 3.4.1 动机

即使经过对抗训练，不同被试的模型输出分布仍存在系统性差异。直接比较原始概率会导致跨被试偏差。例如，某个被试的原始概率普遍偏高，另一个被试普遍偏低。

#### 3.4.2 方法

对每个测试被试，将其所有窗口的 logit 转换为秩百分位：

$$\text{rank}(x) = \frac{\text{rank}(x) - 0.5}{N}$$

其中，rank(x) 是 x 在该被试内的秩，N 是该被试的总窗口数。

#### 3.4.3 特点

1. **不使用测试标签**：校准仅利用未标注窗口的分布，不读取测试标签，适用于离线批评价场景。

2. **非参数稳健性**：秩转换对异常值不敏感，比 z-score 等方法更稳健。

3. **转导式学习**：利用测试集的整体分布信息，但不使用标签，属于转导式学习（transductive learning）。

### 3.5 实验协议与评价方法

#### 3.5.1 训练配置

| 超参数 | 值 |
|--------|-----|
| 模型维度 | 96 |
| Transformer 层数 | 3 |
| 注意力头数 | 4 |
| 最大 epoch | 80 |
| 早停 patience | 16 |
| 每折 batch size | 24 |
| 种子数 | 3（每折独立训练） |
| 总训练次数 | 30（10 折 × 3 种子） |

#### 3.5.2 评价方法

**主指标**：被试级状态 AUC

对每个被试，计算清醒和困倦窗口的平均预测概率，比较清醒和困倦的平均概率，得到正确排序的被试数，计算 AUC 作为主指标。

**统计推断**：被试整群 bootstrap

从 10 名被试中有放回抽样 10 名，重复 B=2000 次，得到 bootstrap 分布，计算 95% 置信区间。

**预注册判定标准**：

1. 主方法 AUC ≥ 0.75
2. bootstrap 95% 下界 > 0.50
3. 相对 raw ensemble 提升 ≥ 0.05 且下界 > 0
4. 相对 v7 基线提升 ≥ 0.05 且下界 > 0

四项同时满足才判定为 `supported`。

## 四、专业实践取得的成果

### 4.1 主方法性能

**核心结果**如表 1 所示。

**表 1  不同方法的 AUC 比较**

| 方法 | AUC | 95% 置信区间 |
|------|-----|-------------|
| **v1.2 rank 校准（主方法）** | **0.880** | **[0.610, 1.000]** |
| v1.2 raw ensemble | 0.710 | [0.420, 0.950] |
| v7 global 基线 | 0.670 | [0.330, 0.970] |

**判定**：主方法满足全部四项预注册条件，判定为 `supported`。

**解读**：主方法 AUC 达到 0.880，显著优于两个基线。bootstrap 置信区间下界为 0.610，远高于 0.50 的随机水平。相对 raw ensemble 和 v7 基线的提升均显著（下界 > 0）。

### 4.2 多种子融合与稳定性

**表 2  单种子与融合性能比较**

| 种子 | AUC |
|------|-----|
| Seed 2026112121 | 0.770 |
| Seed 2026112122 | 0.690 |
| Seed 2026112123 | 0.650 |
| **三种子融合（raw）** | **0.710** |

三个独立种子的 AUC 分别为 0.770、0.690、0.650，体现了不同随机初始化下的性能变异。三种子融合后的 raw ensemble 达到 0.710，优于多数单种子表现，验证了融合策略在降低方差、提升稳定性方面的价值。

### 4.3 校准方法比较

**表 3  不同校准方法的性能比较**

| 校准方法 | AUC | 正确排序被试数 |
|----------|-----|----------------|
| raw（未校准） | 0.710 | 9/10 |
| center（中位数中心化） | 0.880 | 9/10 |
| z-score（标准化） | 0.870 | 9/10 |
| **rank（秩百分位）** | **0.880** | **9/10** |

三种校准方法均显著优于 raw，验证了受试者内校准的有效性。rank 校准在保持非参数稳健性的同时达到最佳性能，因此作为主方法。10 名配对被试中，9 名实现正确的清醒 - 困倦排序，性能不依赖于单个被试。

## 五、结论

本项目完成了基于深度学习的眼电信号疲劳状态识别方法研究。主要成果包括：

1. **提出了 SI-MSET 模型**：采用三分支多尺度时序编码、Transformer 编码器、受试者对抗约束和配对排序损失，在 DROZY 数据集上达到 AUC 0.880。

2. **验证了受试者内校准的有效性**：三种校准方法（center、z-score、rank）均显著优于未校准基线，其中 rank 校准达到最佳性能（AUC = 0.880）。

3. **形成了可复现的研究产物**：包括完整的模型实现、训练代码、配置、实验结果和可视化脚本，支持他人复现和扩展。

4. **预注册判定全部通过**：四项预注册条件（AUC≥0.75、bootstrap 下界>0.50、相对两个基线的提升显著）全部满足。

本次实践表明，深度学习方法在疲劳状态识别任务上具有良好潜力。受试者内校准作为一种简单有效的技术，能够显著提升跨被试泛化能力。未来工作包括在更大数据集上验证方法、探索实时应用场景，以及结合多模态信号（如 EEG、ECG）进一步提升性能。
