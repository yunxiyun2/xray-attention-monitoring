## 插入方法

1. **Word 插入**：
   - 在相应位置点击"插入" → "图片" → 选择 PNG 或 PDF 文件
   - 调整图片大小，保持清晰
   - 添加图题和图号（如"图 1  X-Ray 项目研究流程总览"）

2. **图题格式**：
   - 图号用"图 1"、"图 2"等
   - 图题居中，放在图下方
   - 字体：宋体小四或五号

3. **交叉引用**：
   - 正文中引用图件时用"如图 1 所示"、"见图 3"等

## 图件说明文字示例

### 图 1 插入后的说明

> 图 1 展示了从数据到模型的整体研究流程。DROZY 数据集包含 14 名被试、36 条记录，经过质量控制后得到 2044 个有效窗口。早期探索提示我们需要更强的表征能力，这导向了 SI-MSET 深度模型的设计，最终在 v1.2 达到 AUC 0.880。

### 图 3 插入后的说明

> 如图 3 所示，v1.2 rank 校准方法（蓝色曲线）的 AUC 达到 0.880，显著优于 v7 基线方法（橙色曲线，AUC=0.670）。bootstrap 置信区间为 [0.610, 1.000]，下界远高于随机水平。

## 注意事项

1. **图片格式**：优先使用 PDF（矢量图），放大不失真；PNG 也可用（220 DPI）
2. **图片大小**：单栏宽度约 7-8cm，双栏宽度约 15-16cm
3. **图题位置**：图下方，居中
4. **图号顺序**：按正文出现顺序编号
5. **引用一致**：正文中引用的图号要与实际图号一致
