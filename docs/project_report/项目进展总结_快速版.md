## 二、研究问题与假设

### 核心问题

在仅有 EOG 通道的公开 DROZY 数据集上：
1. 能否构造可解释的眼动代理指标？
2. 这些指标是否支持"驱动衰减"和"分布—转移共变"两个候选成分？
3. 预定义的双成分分数能否比单一疲劳总分更有效地区分清醒和困倦状态？

### 可证伪假设

| 假设 | 内容 | 判定 | 关键证据 |
|---|---|---|---|
| H1 | 预定义眼电代理指标能构造可复现的被试内行为特征 | **通过** | 2088→2044 窗口审计 |
| H2 | 候选指标支持稳定的两成分结构 | **不通过** | v6 Decision B, Heywood case |
| H3 | 双成分模型相对单一疲劳总分具有正向增量 AUC | **不确定** | ΔAUC = −0.150, CI 覆盖零 |
| H4 | SI-MSET 在 LOSO 下达到 AUC ≥ 0.75 | **通过（有条件）** | v1.2 rank 校准 AUC = 0.880 |

## 三、七项候选指标

| 指标 | 含义 | 单位 | 疲劳方向假设 |
|---|---|---|---|
| FD | 平均注视时长 | 秒 | 困倦时增加 ↑ |
| PSV | 扫视峰值速度均值 | °/s | 困倦时降低 ↓ |
| SA | 扫视幅度均值 | ° | 困倦时降低 ↓ |
| FN | 单位时间注视事件频率 | Hz | 困倦时降低 ↓ |
| SE | 注视点空间分布熵 | bits | 困倦时增加 ↑ |
| GTE | 相邻网格联合熵 | bits | 困倦时增加 ↑ |
| SV | 注视点协方差迹 | deg² | 困倦时增加 ↑ |

**预定义分数**：
- F1 = (FD↑ + PSV↓ + SA↓ + FN↓) / 4（驱动衰减因子）
- F2 = (SE↑ + GTE↑ + SV↑) / 3（分布—转移因子）
- global = (F1 + F2) / 2（全局疲劳分数）

## 四、各阶段结果

### v5：方法修正与模拟校准

**修正内容**：
- 非迭代 PCA → 迭代 PAF（主轴因子分析）
- 重叠窗口 → 非重叠窗口（避免数据泄漏）
- 均值退化 → 标准化处理

**模拟校准**：7 类场景，每类 200 组
- 强双因子：200/200 通过 ✓
- 非正态双因子：200/200 通过 ✓
- 其余 5 类（Null、单因子、交叉载荷、异质、非正交）：0/200 通过 ✓

### v6：真实数据 EFA

**平行分析**：
- 七指标在三个非重叠相位均建议 2 个维度
- 但平行分析仅提示维度数量，不证明因子模型成立

**真实数据 PAF 估计**：
- 二因子模型在所有三个相位均出现 **Heywood case**（方差估计为负或载荷>1）
- 整人 cluster bootstrap 汇总为 `not_evaluable`
- SE 与 GTE 的加权相关约 **0.899**，显示候选组内存在明显冗余

**判定**：`Decision B` —— 候选双因子结构未能稳定估计

### v7：增量预测效度

**设计**：
- 10 名同时具有清醒和困倦记录的配对被试
- 被试级留一交叉验证（LOSO）：每折用 9 人训练标准化器和 L2 逻辑回归
- 固定比较 global、F1-only、F2-only、F1+F2 和七指标堆叠

**主结果**：

| 模型 | AUC | 95% CI |
|---|---:|---:|
| 单一疲劳总分 global | 0.670 | [0.330, 0.970] |
| F1 only | 0.640 | [0.300, 0.970] |
| F2 only | 0.010 | [0.000, 0.090] |
| F1+F2 | 0.520 | [0.180, 0.880] |
| 七指标堆叠 | 0.700 | [0.350, 1.000] |
| **F1+F2 − global** | **−0.150** | **[−0.470, 0.140]** |

**判定**：`inconclusive` —— 双成分未显示增量价值，置信区间覆盖零

### v1：SI-MSET 深度模型（单 seed）

**动机**：
- 代理指标路线未能验证稳定结构，预测 AUC 也有限（0.670）
- 转向原始 EOG 信号，用深度学习自动学习时序表征

**模型架构**：
- 输入：原始 EOG-H、EOG-V 和速度幅值（三分支）
- 编码：多尺度时序卷积 + 3 层 Transformer（96 维，4 头）
- 约束：受试者对抗分类（梯度反转）、清醒/困倦配对排序损失
- 评价：10 折 LOSO，测试被试完全不参与训练或早停

**结果**：AUC = 0.750，`inconclusive`（差值区间较宽）

### v1.1：模型扩容

**更改**：增加层数（3→5）、维度（96→128）、epoch（80→130）

**结果**：AUC = 0.720，`inconclusive`（性能反而下降，log loss 恶化）

### v1.2：多种子融合 + 受试者内校准（✓ 主判定 supported）

**协议**：
- 每个 LOSO 折独立训练 3 个随机种子（2026112121/22/23）
- 融合三个 seed 的窗口 logit
- 对比四种校准方法：raw、center、z-score、rank
- 主方法：**three-seed ensemble + subject rank calibration**

**主结果**：

| 指标 | 结果 |
|---|---:|
| 单 seed AUC（3 个） | 0.770 / 0.690 / 0.650 |
| three-seed raw ensemble | 0.710 |
| center calibration | 0.880 |
| z-score calibration | 0.870 |
| **rank calibration（主方法）** | **0.880** |
| 主方法 bootstrap 95% CI | [0.610, 1.000] |
| rank − raw ΔAUC | +0.170 [0.030, 0.300] |
| rank − v7 global ΔAUC | +0.210 [0.030, 0.420] |

**判定**：`supported` —— 四项预注册条件均满足

**关键说明**：
1. 三个单 seed AUC 跨度 0.120，融合后 raw 为 0.710，**低于最佳单 seed**
2. 校准只使用测试被试的窗口分数分布（**不读取标签**），适用于离线批评价
3. 10 名配对被试中，主方法保持 **9/10** 的清醒—困倦排序正确
4. 置信区间仍宽（0.610–1.000），相对两个基线的下界都只有 **0.030**

## 七、注意事项（重要！）

### 不能写的表述

❌ "发现双因子"
❌ "双因子可分离成立"
❌ "双因子提高准确率"
❌ "教师已验收"（除非确有此事）
❌ "论文已投稿/已发表"（除非确有此事）

### 可以写的表述

✅ "候选结构未获支持"
✅ "增量价值不确定"
✅ "负结果证据"
✅ "可复现的方法学成果"
✅ "有条件支持（需受试者内校准，小样本 LOSO）"

### 关键区分

1. **2044 是有效窗口数**；配对被试只有 10 人，分类分析以被试为单位
2. **PAF 的 Heywood case 是结构估计失败证据**，不是"已经证明数据中不存在任何二维关系"
3. **实践成果不以高 AUC 为前提**；完成的工具链、审计过程和可复现负结果同样属于工程实践成果
4. **三个单 seed AUC 跨度 0.120**，不能把 0.880 描述为"模型在不同初始化下都稳定达到该水平"
5. **校准不读取测试标签**，只使用同一测试被试全部窗口的模型分数分布
