## 1. 执行事实

- 输入：`results/dual_factor_efa/indicator_matrix.csv`，SHA256 `e20c60040c6ceb7dfa72b8a1567c430cbaedb0d01adac15fa1ee8a27390d4138`。
- 运行平台：Linux x86_64。
- 配置：30 秒窗、10 秒步长、phase 0；KSS ≤ 4 为清醒，KSS ≥ 6 为困倦；每折使用 L2 逻辑回归，`C=0.1`。
- 被试整合：14 人中 10 人同时有清醒和困倦记录；被试 3、9、12、14 因缺少相反状态被排除。纳入后共 20 条被试-状态记录。
- 交叉验证：10 折被试留一；同一被试的清醒/困倦记录始终留在同一折。
- 随机推断：被试整群 bootstrap，2000 次；同一抽样同时用于模型 AUC 与配对差值区间。

## 2. 核心结果

| 模型 | 外样本 ROC AUC | 被试整群 bootstrap 95% CI |
|---|---:|---:|
| global | 0.670 | [0.330, 0.970] |
| F1 only | 0.640 | [0.300, 0.970] |
| F2 only | 0.010 | [0.000, 0.090] |
| two_factor | 0.520 | [0.180, 0.880] |
| seven_feature | 0.700 | [0.350, 1.000] |
| **two_factor − global** | **−0.150** | **[−0.470, 0.140]** |

主判定为 `inconclusive`。依据 SPEC 预注册门槛：差值未满足 `point ΔAUC ≥ 0.05` 且下界 > 0；也不是差值小于 0 且上界 < 0。因此既不能声明双分数有增量，也不能声明单一总分稳定更好或等价。

## 3. 可报告的结论

1. **增量假设未获支持**：加入 F2 后的外样本 AUC 从单分数基线的 0.670 下降到 0.520，点估计为负，置信区间覆盖 0。报告时应写“未显示增量预测价值”，不能写“F2 有独立贡献”。
2. **F1/单一总分只有弱判别**：global 与 F1 的外样本 AUC 分别为 0.670 和 0.640，CI 很宽，不能推广为稳健的疲劳检测器。
3. **七项堆叠不构成结构性证据**：seven_feature 的 0.700 只说明在固定线性模型和当前小样本上略好于 global；区间仍覆盖很宽，且不回应任何潜因子效率。
4. **F2 方向信号不稳**：F2 模型的外样本 AUC 为 0.010，提示预测分数在当次留出折中几乎反向；但原始 F2 分数的描述性 AUC 只有 0.48，F2 的被试配对正方向也仅 6/10。这主要是训练折系数方向和小样本共同造成的，不能据此宣称 F2 被稳定证明为“反向判别器”。
5. **v6 结论不变**：本次结果属于预测效度检验，不重新解释 v6 的 EFA/PAF 失败，也不能升级为双因子结构成立或否定。

## 5. 后续边界

- 在不引入新外部数据或独立测量验证的情况下，不建议继续调阈值、换分类器、翻转 F2 或继续试删指标来寻找更高 AUC。
- 后续若继续研究，应优先考虑：真实眼动/EOG 测量效度验证、外部数据集结构复验，或明确把当前结果作为小样本负结果/不确定性结果报告。
