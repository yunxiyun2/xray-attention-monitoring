# 双周研究进展汇报

汇报人：邓云溪

覆盖周期：2026年11月16日—2026年11月28日  
研究主线：基于原始双通道 EOG 的 SI-MSET 跨被试疲劳状态识别  
主运行：20261121T103544Z-2de47193（si-mset-v1.2，DROZY）

## 一、研究进展概述

本期完成了研究主线从候选眼动指标结构分析向原始 EOG 时序建模的切换与验证。在 DROZY 的 10 名清醒/困倦配对被试上，SI-MSET v1.2 完成 10 折 LOSO、3 个预先指定随机种子共 30 次训练；三种子融合后采用受试者内 rank 校准，主 AUC 为 0.880（95% CI：[0.610，1.000]），预注册主判定为 supported。同期完成随机种子、校准策略和基线对照分析，并将实测结果整理进专业实践报告材料。

## 二、本期主要工作

### 2.1 明确当前研究路线

上一阶段的候选双因子 EFA 与评分增量预测未能形成支持性结论。本期将研究重点转到原始 EOG-H、EOG-V 时序输入，通过多尺度时序编码与 Transformer 学习跨被试状态表征；v1、v1.1、v1.2 作为同一 SI-MSET 路线的迭代版本，v1.2 为当前主模型。

### 2.2 完成 v1.2 主实验与预注册判定

沿用固定数据缓存及被试级 LOSO 划分，每折训练 3 个种子，并对窗口 logits 等权融合。主方案预先设定为 subject rank calibration。10 折及全部 30 次训练均完成，运行记录、逐折指标、随机种子结果和 bootstrap 样本均已保存。

### 2.3 完成校准与随机种子敏感性分析

对同一三种子融合结果比较 raw、center、z-score、rank 四种评分方式，并完成逐被试剔除分析。结果显示 rank 与 center AUC 均为 0.880，z-score 为 0.870，raw ensemble 为 0.710；rank 相对 raw 的配对提升为 +0.170（95% CI：[+0.030，+0.300]）。三个单 seed AUC 分别为 0.770、0.690、0.650，模型结果仍有初始化波动。逐被试剔除后，rank AUC 最低为 0.864。

### 2.4 整理基线比较与报告材料

已形成 v1.2 实验结果分析稿，归纳主结果、校准敏感性、历史 v1 消融、参数设置及待补实验。报告同时明确了 rank 校准使用整段测试被试的未标注分数分布，属于离线批评价设定。

## 三、核心实测结果

| 指标/方法 | 结果 | 说明 |
|---|---:|---|
| v1.2 主方法：三种子融合 + rank | AUC 0.880（95% CI：[0.610，1.000]） | 10 名配对被试，预注册主方法 |
| three-seed raw ensemble | AUC 0.710 | 同一模型输出，未作被试内校准 |
| center 校准 | AUC 0.880 | 与 rank 的 AUC 点估计并列 |
| z-score 校准 | AUC 0.870 | 同协议敏感性比较 |
| rank − raw | +0.170（95% CI：[+0.030，+0.300]） | 被试级配对 bootstrap |
| rank − v7 global | +0.210（95% CI：[+0.030，+0.420]） | 与项目既有 global 基线比较 |
| 单 seed AUC | 0.770 / 0.690 / 0.650 | 三个种子结果跨度为 0.120 |
| 正确排序被试数 | 9/10 | rank 主方法 |

当前结果支持“SI-MSET 与受试者内校准结合后，在本 DROZY 离线评价协议下取得较好的被试级状态排序”。该结论不扩展为跨设备泛化或实时单窗口推断。

## 四、消融进展与待解决事项

已有消融结果属于 SI-MSET v1：full AUC 为 0.750，single-scale、no-adversarial、binary-only 分别为 0.730、0.740、0.730；三组配对 ΔAUC 的 95% CI 均覆盖 0。这些结果可作为早期版本诊断，不能用于判定 v1.2 各组件的贡献。

v1.2 的 single-scale、no-adversarial、binary-only 三项同协议消融尚未实跑，因此当前还不能对 v1.2 多尺度结构、受试者对抗约束和辅助序数监督分别作贡献结论。完成该实验需要可访问的 v1.2 训练张量缓存及训练算力；当前本地缓存目录没有 windows.npy，训练服务器也暂不可用。

另未对模型宽度、Transformer 层数、dropout 和学习率进行系统扫描。当前参数是 v1.2 实际采用的配置，不作为已验证的最优参数。
